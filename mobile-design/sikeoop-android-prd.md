# sikeoop 安卓版需求（PRD）

> 2026-10-09。只写「要做什么」。技术方案见 `sikeoop-android.md`，页面线框见 `sikeoop-android-wireframes.md`，验收清单见 `sikeoop-android.md` §13。

## 1. 目标

把电脑上的鲸鱼娘装进口袋：

1. 说一句话就能派活；
2. 随时看得到她在干什么；
3. 需要你时，在通知栏点一下就能做决定；
4. 做完收到一份说人话的回执。

要解决的问题：微信远程只能收发文字，看不到进度和改动；懒人模式的进度、回执、撤销，人一离开电脑就够不着。

## 2. 范围

| 线 | 内容 | 什么时候 |
|---|---|---|
| A 线 | 手机遥控电脑上的 sikeoop | MVP，先做 |
| B 线 | 在手机上本地写网页 | 内测，技术验证通过后才显示入口 |

**明确不做**：远程桌面画面、在手机上往终端打字、iOS 版、多人协作、App 自己下载 shell 或系统镜像、本地大模型、营销推送、锁屏上显示命令或代码。

## 3. A 线：遥控电脑

### 3.1 配对

1. 电脑上的「手机」页点「添加手机」，出一张二维码：一次性、5 分钟过期。
2. 手机扫码（不依赖谷歌服务），生成设备密钥，私钥加密存在手机里。
3. 电脑弹窗确认「允许这台手机遥控吗」，允许后进设备列表，以后自动重连。
4. 电脑随时可移除设备，移除后手机立刻断开。一台手机先只绑一台电脑。

### 3.2 首页「本鲸」

- 大头像跟着任务状态切换：

| 状态 | 形象 | 一句话（示意） | 主区域 | 主按钮 |
|---|---|---|---|---|
| 空闲 | `sleepy.svg` | 没活干，快派~ | 最近一条回执 | 发送 |
| 干活 | `work.svg` | 本鲸在干活，别吵~ | 进度卡（计划第几步、正在做什么） | 停下 |
| 等你 | `waiting.svg` | 有事要你拍板 | 审批卡，「待办」挂数字 | 同意 / 拒绝 |
| 做完 | `lazy.svg` | 做完了，来夸本鲸~ | 回执摘要 | 看回执 |
| 出错（含被拒答） | `error.svg` | 出岔子了 | 一句话原因 | 重试 |
| 没做完（步数用完、已停下） | `sleepy.svg` | 还没做完 | 一句话原因 | 继续 |
| 电脑不在线 | `sleepy.svg` 变灰 | 电脑睡着了 | 上次在线时间 | 重新连接 |

- 其余元素：电脑在线状态与当前项目、输入框（说一句话派活，可用输入法语音）、快捷指令 4 条（继续 / 停下 / 跑测试修一下 / 总结改了啥）。
- 电脑不在线时输入框禁用，只留「重新连接」。

### 3.3 任务详情

- 帮我干活的那一句原文；
- 计划步骤，四种状态：完成 / 进行中 / 待做 / 跳过；
- 现在正在做什么（含已跑时间）；
- 终端里的 AI（Claude Code / Codex）各自的状态；
- 「停下」按钮。

### 3.4 待办

**要你拍板**：审批卡一张一条，带倒计时（还剩多久），按钮「拒绝 / 同意」。来源三种：AI 的审批、AI 的提问、终端里 Claude Code / Codex 的权限请求。超时了、或已经在电脑 / 微信上处理过的，卡片置灰并写明原因。

**回执**：按时间倒序的回执列表，点开是回执详情：

- 鲸鱼娘的一句话总结；
- 这一轮改了哪些文件；
- 被拦下的事（懒人模式拦掉的操作，各写原因）；
- 本鲸自己做的决定；
- 「撤销这一轮」，撤销前弹确认：文件回到修改前，命令做过的事撤不回。

### 3.5 通知（不打开 App 也知道她在干嘛）

| 时机 | 内容 | 按钮 |
|---|---|---|
| 任务进行中 | 常驻一条，一行进度 | 停下 |
| 要你拍板 | 高优先级，写明谁要干什么 | 同意 / 拒绝 / 打开 |
| 锁屏时 | 只写「有 1 件事要你拍板」 | 同意 / 拒绝（先解锁才能点） |
| 做完 | 「做完了：改了 3 个文件」 | 看改动 / 撤销 |

- 锁屏通知里不显示命令、代码、文件名；撤不回的操作要先解锁才能同意。
- 通知文字只写一句事实。

### 3.6 模式与拦截

- 远程任务固定用懒人模式的拦截规则（MVP 不给模式开关）。
- 危险操作照旧自动拦下（sudo、删项目外的文件、改系统设置等），手机上也不给放行。
- 推送、发布这类撤不回的操作：在手机上逐条确认，「全部同意」代替不了，10 分钟没人回按拒绝。
- 电脑上的切项目、换服务商等会打断任务时，回执里写明「被电脑那边打断了」。
- 手机不在线时，回执和终端 AI 的权限请求改发到微信（微信远程开着的话）。

### 3.7 手机能做 / 不能做

- **能**：派活、停下、审批、回答提问、撤销本轮、看 diff、看终端里的 AI 并批准它们的权限。
- **不能**：改模型和 Key、装插件 / MCP / Mod、往终端里打字、读项目以外的文件、打开「最近打开」以外的文件夹。

### 3.8 其他页面

- **首次打开**：欢迎 → 扫码配对 → 保活引导（允许通知、电池不限制、后台自启动）→ 首页。保活没做完也能进，首页挂提示条。
- **我的**：我的电脑（查看 / 移除 / 换一台）、快捷指令（只读的 4 条）、通知与保活检查、微信兜底状态、关于。
- **对话页**：照搬桌面版 ChatPanel 的行为，改成手指好点的尺寸（流式 Markdown、工具调用收成一行、计划进度、撤销条）。
- **改动页**：这一轮每个文件一份 diff。

## 4. B 线：本机编程（内测）

- **项目**：放在 App 私有目录。模板三种：空白网页、计时器、小游戏。zip 导入（系统文件选择器）导出（系统分享）。
- **本地对话**：模式只有懒人 / Agent 两种；Agent 模式每步弹审批卡，内容同桌面。
- **预览**：WebView 里跑真实网页，带刷新。
- **模型与 Key**：手机上填，加密存在本机；也可以从电脑导入配置（两边都确认）。服务商列表和「获取模型列表」沿用桌面做法。
- **没有 shell**：不注册命令工具，要跑命令的活儿做不了。
- 技术验证（2 天，和 A 线并行）没通过之前，「项目」入口不显示。git 同步、「发到电脑」后做。

## 5. 素材（`whale-girl-svg/`）

| 用途 | 文件 |
|---|---|
| 空闲 / 没做完 / 离线（变灰） | `sleepy.svg` |
| 干活 | `work.svg` |
| 等你 | `waiting.svg` |
| 做完 | `lazy.svg` |
| 出错 | `error.svg` |

- P1 先用静止画面，动画版放 P3；首页头像不要把多个 SVG 内联进同一页面（id 会互相覆盖）。
- 通知栏小图标要用单色鲸鱼头剪影，待出一张。

## 6. 统一规则

1. 通知和锁屏只写一句事实，不带命令和代码，不用嘴毒语气；嘴毒只出现在 App 里鲸鱼娘的对话气泡中。
2. 每张审批卡都显示倒计时；超时、或已在电脑 / 微信处理的，置灰并写明原因。
3. 同时有多条审批就显示多张卡，按钮只管自己那条。
4. 电脑不在线时输入框禁用，只留「重新连接」。

## 7. 分期

| 阶段 | 内容 | 完成标准 |
|---|---|---|
| P0 | 定协议接口、契约样例、加密规格、Android 工程骨架 | typecheck 不新增错误；打包通过；两端都能解析契约样例 |
| P1 | 遥控 MVP（走中继）：配对、首页、对话、审批、回执、通知、保活引导 | 验收清单 1–9 条 |
| 并行 | 本机技术验证 | 跑通一轮「读、改、撤销」，冷启动 ≤ 3 秒 |
| P2 | 本机轻量档：拆内核、自带 Node、本地项目、预览、Key | 验收清单 10 条 |
| P3 | 加强：局域网直连、小组件、语音、多项目等 | 每项单独验收 |
| P4 | 本机完整档（Termux） | 在 Termux 里跑通一轮要执行命令的任务 |
| P5 | 发布：签名、官网下载、检查更新 | 能从官网下到签好名的 APK |
