# sikeoop 安卓版：页面线框（低保真）

> 设计稿 `sikeoop-android.md` 的附件。日期：2026-10-09。
> 线框由产品经理子代理出稿。指挥官按已经定下的选择改了 5 处，见下面的「改了什么」。
> 线框只定页面结构和内容。配色、鲸鱼娘形象、动效交给 Claude 军团的 ui-engineer。
> 文案只是示意。框线按等宽字体对齐，一个中文字占两格。

图例：
- `>`：可以点进去。
- `v`：下拉。
- `[文字]`：按钮。
- `[x] [>] [ ] [-]`：依次表示完成、进行中、待做、跳过。

**改了什么**：原稿把「推送、发布」画成「一律拦下」，和用户定的「在手机上一键确认」冲突。
1. 待办页：加了一张撤不回操作的确认卡。
2. 回执页：加了「你拍板的事」，「被拦下的事」改用 sudo 举例。
3. 「我的」页：底部说明改成「推送和发布会在手机上问你」。
4. 任务详情：加了「看完整对话」入口（对应设计稿 §4 的对话页），计划里的「推送」改成「要你确认」。
5. 扫码页：电脑上的入口改成「手机」页。

原稿还提出「远程任务固定用懒人模式，不给模式开关」。这和设计稿正文的「默认懒人，可以切换」不一样，先记在设计稿 §15 第 4 条，等用户定。

## 导航

```
首次打开  欢迎 -> 扫码配对 -> 保活引导 -> 首页
底部标签  首页 | 待办 | 项目(本地,过门后) | 我的
首页 -> 任务详情 -> 完整对话   待办 -> 回执详情
我的 -> 我的电脑 / 快捷指令 / 模型与Key / 通知与保活检查(同第3页)
项目 -> 本地对话 -> 预览
通知栏：点按钮直接处理，点正文进对应页
```

## 4. 首页（以「干活中」为例）

```
+--------------------------------+
| 我的 MacBook  在线  [懒人]     |
| 项目：shop-web                 |
|                                |
|         [鲸鱼娘 干活]          |
|      "本鲸在干活，别吵~"       |
|                                |
| +----------------------------+ |
| | 计划 2/5  [====------]     | |
| | 正在：运行 npm test        | |
| | Claude-1 干活中            | |
| |            [停下]  [详情>] | |
| +----------------------------+ |
|                                |
| [继续] [停下] [跑测试修一下]>  |
| +--------------------+ +----+  |
| | 说一句话派活...    | |发送|  |
| +--------------------+ +----+  |
+--------------------------------+
|[首页]   待办    项目    我的   |
+--------------------------------+
```

说明：快捷指令可以横向滑动，一共 4 条。其他状态见下表。

| 状态 | 形象（素材在 `whale-girl-svg/`） | 一句话（示意） | 主区域 | 主按钮 |
|---|---|---|---|---|
| 空闲 | `sleepy.svg` 点头打盹 | 没活干，快派~ | 最近一条回执 | 发送 |
| 干活 | `work.svg` 敲键盘 | 本鲸在干活，别吵~ | 进度卡 | 停下 |
| 等你 | `waiting.svg` 看手机等你 | 有事要你拍板 | 审批卡，「待办」标签上挂数字 | 同意 / 拒绝 |
| 做完 | `lazy.svg` 摸鱼玩泡泡 | 做完了，来夸本鲸~ | 回执摘要 | 看回执 |
| 出错（包括被拒答） | `error.svg` 慌张地抖 | 出岔子了 | 一句话说明原因 | 重试 |
| 没做完（步数用完、已停下） | `sleepy.svg` | 还没做完 | 一句话说明原因：步数用完，或者已经停下 | 继续 |
| 电脑不在线 | sleepy 变灰 | 电脑睡着了 | 上次在线时间；输入框禁用 | 重新连接 |

原稿里的「趴着发呆、举手、叉腰」是没有素材时设想的姿势，现在作废，以 `whale-girl-svg/` 里的素材为准。

## 8. 回执详情

```
+--------------------------------+
|  <  回执              14:20    |
|                                |
|  [鲸鱼娘 偷懒]                 |
|  "修好了，登录不再 500。"      |
|                                |
|  改了 3 个文件            >    |
|   M src/api/login.ts           |
|   M src/config.ts              |
|   A tests/login.test.ts        |
|                                |
|  你拍板的事 (1)                |
|   git push：你同意了，已推送   |
|                                |
|  被拦下的事 (1)                |
|   sudo 装全局包：要你自己来    |
|                                |
|  本鲸自己做的决定              |
|   用了现有 jest，没装新库      |
|                                |
|       [   撤销这一轮   ]       |
+--------------------------------+
```

说明：
- **被拦下的事**包括两类：
  - 懒人模式硬拦截清单里的操作，比如 sudo、删项目外的文件、改系统设置；
  - 撤不回的操作，你在手机上拒绝了，或者超时没回。
- **本鲸自己做的决定**：懒人模式下，提问会自动按推荐选项回答（loop.ts:905-909），这里列出这些回答。
- **撤销前弹确认**：「3 个文件回到修改前，命令做过的事撤不回。」已经推送出去的也撤不回。

## 统一规则

1. **通知和锁屏的文字**：只写一句事实，不带命令和代码，也不用嘴毒的语气。嘴毒只出现在 App 里鲸鱼娘的气泡中。
2. **审批卡的倒计时**：每张卡都显示倒计时。超时了，或者已经在电脑、微信上处理过，卡片就置灰并写明原因。（验收清单第 12 条）
3. **多条审批**：同时有几条就显示几张卡，每张卡的按钮只管自己那条。
4. **电脑不在线**：输入框禁用，只留「重新连接」。（验收清单第 13 条）
