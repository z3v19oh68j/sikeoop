## 需要指挥官决定的事
1. **怎么判断权限还没答**：前端的规则是「任务状态为 `waiting_approval`，且最近一条权限进度里有卡片」。如果以后一个任务同时挂着多张卡，需要后端在进度里标明哪张卡已经答过了。
2. **「轮次」怎么显示**：后端的状态进度里如果带「第 N 轮」，会原样显示在那一行里。前端没有单独做轮次计数，因为 ACP 的进度里没有结构化的轮次字段。
3. **有没有给用户的提交入口**：这次没有做让用户从界面上发起外部 agent 任务的入口，任务书没要求，而且后端的提交接口只在开发版可用。需要的话下一批再做。
