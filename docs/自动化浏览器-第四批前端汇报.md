## 改动文件
- 新建 `src/renderer/src/components/BrowserFlows.tsx`
  - `FlowsPanel`：浏览器里的「浏览器脚本」面板。
    - 填脚本名、勾选「把填写的内容变成变量」（默认勾选，对应 `values: "parameterize"`），点「开始录制」调用 `browserFlowStartRecording(name, {values})`。说明里写明密码永远不录，录制时别让 AI 同时操作浏览器。
    - 脚本列表：名字、步数、变量数、修复过几次。展开后能看到每一步的说明，下面是变量输入框（变量从步骤里的 `{变量}` 自动收集），变量没填完不能运行。
    - 自愈开关默认关，文案是「这次允许自动修复：找不到按钮或输入框时，会调用 AI 修复失效的步骤（会把当前页面的精简结构发给你设的模型）」。勾选后才传 `{selfHeal: true}`。
    - 运行调用 `browserFlowRun`。成功显示「全部 N 步都做完了」。失败时，在步骤列表里把已完成的步骤标绿、失败那一步标红，并显示「第 N 步失败（完成了 x/y 步）：原因」，页面结构快照放在折叠区里。
    - 删除要二次确认（`browserFlowDelete`）。
  - `FlowStepConfig` 和 `flowStepSummary`：给自动化流程图里「运行浏览器脚本」这一步用（见下）。
- `src/renderer/src/components/BrowserPane.tsx`
  - 地址栏右边加了「浏览器脚本」按钮，点开 FlowsPanel。
  - 录制中，浏览器顶部会出现红色录制条：闪烁的红点 +「正在录制『名字』」+ 提示 +「停止并保存」（`browserFlowStopRecording`）。保存后显示「已保存『名字』，共 N 步」5 秒；停止失败会显示错误。
  - 状态条：
    - 运行中新增「暂停」按钮（`browserAutomationPause`）。
    - 「你接手了」改成看结构化字段 `pauseReason === "user"`；只有字段缺失时才退回旧的关键词判断。
    - `pauseReason === "approval"` 时显示「等你批准：…」，不显示「继续」，也不提示「你接手了」。
- `src/renderer/src/components/AutomationScreen.tsx`
  - 步骤类型下拉里新增「运行浏览器脚本」（`browser_flow`）。
  - 编辑时把文本框换成配置界面：从录好的脚本里选一个；选中后按这个脚本的变量显示输入框；改动直接写成 `{"name": …, "vars": {…}}` 存进 text。没有脚本时提示去内置浏览器录一个。界面上写明「不经过 AI，提交、付款、上传仍然要你批准」。
  - 查看模式下这一步显示地球图标，文字显示成「脚本『名字』· 变量=值」。
  - 切换到命令或浏览器脚本时，只保留「成功 / 失败」两个分支；从浏览器脚本切回其他类型时会清空 text，避免把 JSON 当成提示词或命令。
- `src/renderer/src/styles/theme.css` — 末尾追加录制条、脚本面板、流程图配置的样式；开启「减少动态效果」时关掉红点闪烁。
- `src/renderer/src/dev-mock.ts`（只动了浏览器部分）
  - 补齐 6 项：`browserAutomationPause`、`browserFlowList`、`browserFlowStartRecording`、`browserFlowStopRecording`、`browserFlowRun`、`browserFlowDelete`。
  - 自带两个示例脚本：「每日签到」（含 `{用户名}` 和一步密码）、「查快递」（含 `{单号}`）。
  - 录制：同名脚本或重复开始会报错；停止后生成一个 3 步、带 `{value1}` 的脚本。
  - 回放：第 1 次成功，第 2 次在最后一步失败（原因加页面快照），之后交替。
  - 第三批的演示改成用 `pauseReason: "user"` 模拟「你接手了」；手动暂停用 `pauseReason: "manual"`。

## 需要指挥官决定的事
1. **脚本先起名再录**：任务要求「停止后命名保存」，但后端接口是开始录制时就要给名字（`browserFlowStartRecording(name)`），停止时没有改名参数。所以现在是先起名再录。要支持停止后再命名，需要后端加改名接口，或者让停止录制可以带上名字。
2. **`providerDiscoverModels` 的 mock**：需要派人补上，web typecheck 才能回到 0。
