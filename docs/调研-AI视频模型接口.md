- 标注约定：**【官】** 官方文档或官方协议原文；**【三方】** 第三方文章或转售平台，未经官方核实；**【推断】** 我根据已有信息做的判断。

## 1. 结论

### 推荐顺序

1. **可灵（国内站）**：先接。
2. **火山方舟 Seedance / Seedream**：第二家，用它代替方案里写的“即梦”。
3. **Runway**：放到后面，给人在海外的用户用。
4. 通义万相（阿里云百炼）：备选，这一批不接。

### 理由

- **“即梦”自己的视频接口正在下线。** 火山引擎即梦文档库里，视频生成 3.0 / 3.0 Pro / S2.0 Pro 的接口文档标题全部标了“下线中”或“陆续下线中”【官】。同一个模型家族现在走火山方舟的 Seedance 接口，所以方案里的“即梦”应当改成“火山方舟 Seedance”。【推断：这是替代路径；即梦文档里没有找到写明迁移去向的公告】
- **可灵排第一**，因为它的费用最容易在审批卡上写清：按秒计价，单价只跟模型、分辨率、有无声音有关【官】。鉴权是一个 Bearer Key【官】，手机号登录就能建 Key，文档没有提企业资质【官】。国内有专门的域名【官】。结果保留 30 天【官】，其余几家都是 24 小时左右。无声 720p 的单价也是几家里最低的（0.3 元/秒）【官】。
- **火山方舟排第二**，因为它同样是 Bearer Key + 提交后轮询【官】，官方文档明确给了“个人用户”的限流档位【官】，而且 sikeoop 的服务商预设里已经有方舟的地址（`sweet-code-desktop/src/main/providers/presets.ts:177`），用户很可能已经有 Key。它一把 Key 同时能出图（Seedream，0.12–0.30 元/张）【官】。排在可灵后面的原因是：开通 Seedance 2.x 要账户余额满 200 元【官】，价格按 token 算、要用公式换算【官】，视频链接只有 24 小时【官】。
- **Runway 后置**，因为它用美元信用点计价，最低充 10 美元【官】；被内容审核拦下的生成照样扣费，拦截太多会封号【官】；条款要求接入方在界面上显示“Powered by Runway”【官】；大陆能否直连没有查到官方说法。
- 可灵和方舟的调用形态几乎一样（Bearer Key、提交任务、轮询、下载结果），**做一层统一适配后两家可以在同一批里接完**。【推断】

## 2. 可灵（快手）

**入口与资质**

- 国内站文档：<https://klingai.com/document-api/guides/get-started/quick-start.md>。登录方式原文：“使用您的手机号或快手扫码登录，控制台账号与可灵AI web端账号一致”【官】。页面没有提实名认证或企业认证【官】。
- 国内站付费协议要求“注册或登录「可灵AI」，绑定快手账号”，没有区分个人和企业，也没有实名条款【官】：<https://klingai.com/document-api/guides/protocols/paid-service.md>
- 国际站文档：<https://kling.ai/document-api/guides/get-started/quick-start.md>，用邮箱登录【官】。国际站协议把用户定义为“the individual accepting this Agreement”【官】。
- 【推断】个人可以自助开通，不需要企业资质。没有实际注册验证过。

**鉴权**

- 在控制台新建 API Key，请求头 `Authorization: Bearer <Key>`；Key 只显示一次【官】。
- 旧版接口用 AccessKey + SecretKey 按 JWT（RFC 7519）生成令牌，示例里有效期是 1800 秒【官】。
- 新旧的区分：模型版本写在请求路径里的是新版，用 `model_name` 参数的是旧版【官】。
- 来源：<https://klingai.com/document-api/api/get-started/authentication.md>
- 【推断】只接新版路径式接口，可以完全避开 JWT。

**域名**

- 国内：`https://api-beijing.klingai.com`，文档称适用于服务器在中国地区的用户【官】。
- 国际：`https://api-singapore.klingai.com`，面向服务器在中国以外的用户【官】。
- 两个站的 Key、计价单位和币种不同，要让用户选站点。【推断：两站账号是否互通未查到】

**生成能力**（以 Kling 3.0 Turbo 为例）

- 文生视频：`POST /text-to-video/kling-3.0-turbo`。分辨率 `720p`、`1080p`；比例 `16:9`、`9:16`、`1:1`；时长 3–15 的整数秒，默认 5【官】。<https://kling.ai/document-api/api/video/3-0-turbo/text-to-video.md>
- 图生视频：`POST /image-to-video/kling-3.0-turbo`。图片支持 jpg / jpeg / png，不超过 50MB，宽高不小于 300px，宽高比 1:2.5 到 2.5:1，可传 URL 或 Base64；目前只支持首帧【官】。<https://kling.ai/document-api/api/video/3-0-turbo/image-to-video.md>
- 文生图：有 Kling Image 3.0、3.0 Omni、O1、2.1 的接口【官】，参数细节没有逐项查。
- 文档索引里还有 3.0、3.0 Omni、2.6、2.5 Turbo 各自的文生视频和图生视频接口【官】：<https://kling.ai/document-api/llms.txt>
- 对口型、数字人、换装等接口也有，方案第一批不做，没有查。

**调用形态**

- 异步任务。状态为 `submitted`、`processing`、`succeeded`、`failed`【官】。
- 查询：`GET /tasks`（按任务 ID 或自定义 ID）【官】。
- 回调：创建任务时可传 `callback_url`，可启用签名校验（`webhook-id`、`webhook-timestamp`、`webhook-signature`）；文档没有写重试规则【官】。<https://kling.ai/document-api/api/get-started/callbacks.md>
- 桌面应用没有公网地址，用轮询。【推断】
- 并发：上限跟资源包档位有关，超限返回错误码 1303；查询不占并发，文档称没有 QPS 限制【官】。各档位的具体并发数未查到。<https://kling.ai/document-api/api/get-started/concurrency-rules.md>

## 3. 火山方舟 Seedance / Seedream（即梦同源模型的现行接口）

**入口与资质**

- 开通 Seedance 2.5 和 2.0 系列需满足任一条件：账户可用余额达到 200 元，或购买 200 元及以上的节省计划，或购买 200 元及以上的资源包【官】。<https://www.volcengine.com/docs/82379/2637911>
- 模型开通期间，余额里不超过 200 元的部分不能提现，关闭模型后可以提现【官】。
- 模型列表对 Seedance 2.x 分别给了“企业用户”和“个人用户”的限流：个人最大 RPM 180、最大并发 3，企业 600 和 10【官】。这说明个人账号可以调用。<https://www.volcengine.com/docs/82379/1330310>
- 火山引擎账号需要实名认证后才能开通服务（这句出自即梦的快速入门，方舟是否相同为【推断】）。
- 2026 年 4 月的报道称 Seedance 2.0 API 向“企业和个人用户”开放【三方】：<https://news.qq.com/rain/a/20260414A04M1I00>

**鉴权**

- `Authorization: Bearer $ARK_API_KEY`，在控制台的 API Key 管理页获取长效 Key【官】。也支持 Access Key 签名，面向企业精细化管理【官】。<https://www.volcengine.com/docs/82379/1298459>
- 数据面 Base URL：`https://ark.cn-beijing.volces.com/api/v3`【官】，和 sikeoop 现有预设一致。

**生成能力**

- 创建任务：`POST /contents/generations/tasks`【官】。<https://www.volcengine.com/docs/82379/1520757>
- Seedance 2.5 和 2.0 系列都支持文生视频、首帧图生视频、首尾帧图生视频、多模态参考生视频（含视频编辑和延长）【官】。
- 分辨率：2.5 为 480p / 720p / 1080p；2.0 为 480p / 720p / 1080p / 4k；2.0 fast 和 2.0 mini 为 480p / 720p【官】。
- 比例：`16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`21:9`、`adaptive`【官】。2.5 做首帧或首尾帧生视频时只能用 `adaptive`，跟随首帧图片【官】。
- 时长：2.5 为 4–30 秒，2.0 系列为 4–15 秒，都可设 `-1` 让模型自己选；帧率 24【官】。时长影响计费，让模型自选时审批卡上的预估会不准。【推断】
- 图片输入：jpeg、png、webp、bmp、tiff、gif 等，宽高比 0.4–2.5，边长 300–6000px，单张小于 30MB，可传 URL 或 Base64，请求体不超过 64MB【官】。
- 声音：`generate_audio` 默认 `true`【官】。
- 种子：`seed` 参数只列在 Seedance 1.0 系列下【官】，而 1.0 系列在模型列表里标了“即将下线”【官】。方案要求“记录种子方便重来”，在 Seedance 2.x 上可能做不到。【推断】
- 文生图：`POST /images/generations`，模型为 Seedream 5.0 pro / flash / lite、4.5、4.0【官】。<https://www.volcengine.com/docs/82379/1541523>

**调用形态**

- 异步。查询：`GET /contents/generations/tasks/{id}`，状态为 `queued`、`running`、`succeeded`、`failed`、`cancelled`，超时为 `expired`【官】。<https://www.volcengine.com/docs/82379/1521309>
- 回调：可传 `callback_url`，5 秒内未收到成功响应会重发三次【官】。
- 任务默认 48 小时超时，可用 `execution_expires_after` 调整（3600–259200 秒）【官】。只有排队中的任务能取消【官】。
- 典型耗时：官方未给数字，官方教程示例每 30 秒打印一次状态【官】；第三方称通常 1–3 分钟，建议 8–15 秒轮询一次【三方】：<https://clawhub.ai/maddy-cc/seedance-video-volcengine>
- 结果有效期：视频链接和尾帧图链接 24 小时；Seedance 2.5 的视频链接最多下载 100 次；任务记录只能查最近 7 天【官】。图片链接 24 小时内失效【官】。

**计价**（人民币）【官】：<https://www.volcengine.com/docs/82379/1544106>

- 视频按 token 计费。估算公式原文：`(输入视频时长+输出视频时长) × 输出视频的宽 × 输出视频的高 × 输出视频的帧率/1024`，准确用量以返回的 `usage.completion_tokens` 为准。
- 单价（元/百万 token，输入不含视频时）：2.5 为 70（480p / 720p）和 77（1080p）；2.0 为 46（480p / 720p）、51（1080p）、26（4k）；2.0 fast 为 37；2.0 mini 为 23。
- 官方价格示例（16:9，5 秒，输入不含视频）：

| 分辨率 | 2.5 | 2.0 | 2.0 fast | 2.0 mini |
|---|---|---|---|---|
| 480p | 3.36 元 | 2.31 元 | 1.86 元 | 1.16 元 |
| 720p | 7.56 元 | 4.97 元 | 4.00 元 | 2.48 元 |
| 1080p | 18.71 元 | 12.39 元 | 不支持 | 不支持 |
| 4k | 不支持 | 25.27 元 | 不支持 | 不支持 |

- 我用公式验算了 2.0 的 720p 5 秒：5 × 1280 × 720 × 24 / 1024 = 108,000 token，乘 46 元/百万 = 4.97 元，和官方示例一致。审批卡可以用这个公式预估。
- 图片（元/张）：Seedream 5.0 flash 0.12，5.0 lite 0.22，4.5 为 0.25，4.0 为 0.20，5.0 pro 为 0.30（1.5K 及以下）或 0.60（1.5K 以上）；审核等原因未成功输出的图片不计费【官】。
- 视频任务失败或被审核拦截是否计费：未查到。

**商用、水印、审核**

- 视频 `watermark` 默认 `false`，开启后右下角显示“AI 生成”【官】。图片 `watermark` 默认 `true`【官】，接入时要显式关掉或告诉用户。

## 7. 对实现的提示

都是【推断】，供方案参考。

- **统一适配层**：四家都是“提交任务 → 轮询 → 下载结果”，鉴权除即梦外都是 Bearer。接口可以抽成 提交、查询、取消、估价 四个方法。
- **结果必须立即落盘**：链接有效期从 1 小时到 30 天不等，生成成功后马上下载到 `assets/`，不要存链接。方舟 2.5 还有 100 次下载上限。
- **估价**：可灵是 单价 × 秒数；方舟是 token 公式，时长不要用 `-1`；Runway 是 点数 × 秒数 × 0.01 美元。价目表会变，建议做成可更新的数据，并在审批卡上标“预估”。
- **失败重试**：方案写了“失败自动重试一次”。Runway 审核拦截照样扣费，拦截多了会封号，所以审核类失败不应自动重试。可灵和方舟视频的失败计费规则没有查到官方原文，接入前要确认。
- **种子**：方舟 Seedance 2.x 似乎不接受 `seed`，可灵 3.0 Turbo 文档里我也没有看到种子参数（没有专门核对）。方案里“记录种子方便重来”可能要改成“记录完整请求参数”。
- **水印**：方舟图片默认带水印，要显式关闭或让用户选。国内两家的协议都有生成内容标识义务，要不要默认给成片加“AI 生成”标识，需要用户决定。
- **Runway 署名**：接 Runway 的话界面上要显示“Powered by Runway”。
- **站点选择**：可灵国内站和国际站的域名、币种都不同，设置里要让用户选。
