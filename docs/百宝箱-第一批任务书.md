## 0. 约束
- 复用内置浏览器（`src/main/browser/service.ts`、`BrowserPane.tsx`，会话 `persist:sikeoop-browser`），用 `<webview>`，不用 iframe。
- 不代登录、不存别家 Key、不抓取别家内容、不调任何私有接口；不绕验证码。
- 站点图标运行时取 favicon，不打包别家商标图片。
- 不启动应用、不 git 提交；typecheck 0，npm test 全过。

## 1. 接口（后端只新增到 `src/shared/types.ts` / preload）
```ts
export type AiSiteCategory = "cn-search" | "cn-assistant" | "global" | "academic" | "dev" | "custom";
export interface AiSite { id: string; name: string; category: AiSiteCategory; home: string; query?: string /* 含 {q} 的模板；无则复制粘贴 */; note?: string; login: "none" | "optional" | "required"; cnDirect?: boolean }
export interface AiToolboxPrefs { favorites: string[]; order: string[]; hidden: string[]; custom: AiSite[]; groups: { id: string; name: string; sites: string[] }[] }
```
SweetApi（IPC 前缀 `toolbox:`）：`toolboxSites(): AiSite[]`（内置 + 自定义）、`toolboxPrefs()`、`toolboxSavePrefs(p)`、`toolboxOpenUrl(siteId, q?) : { url: string; copied: boolean }`（无模板时把 q 写剪贴板并返回首页）。
自定义站点只允许 http/https，模板必须含 `{q}` 或为空；q 用 encodeURIComponent。

## 2. 清单 `resources/ai-search/sites.json`（终端 Claude Code）
按方案第 3 节逐个用浏览器/curl 实测：首页能否打开、带问题的网址模板是否生效（打开后输入框或结果里出现问题）。生效的写 `query`，不生效或要登录才能验证的不写（留空走复制粘贴），`note` 记一句特点。只访问公开页面，不登录、不提交表单。结果写 `../docs/百宝箱-站点实测.md`。
