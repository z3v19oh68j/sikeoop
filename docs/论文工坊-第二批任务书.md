## 2. 要做的三项

### 2.1 模拟审稿（论文工坊新页签「模拟审稿」）
- 输入：工坊里的一篇论文（PaperDoc），或一段文本 / 项目里的 `.tex` / `.md` 文件。
- 审稿人：用户选 2–5 个不同家的模型（候选来自已配好 Key 的服务商），每人按顶会格式输出结构化结果：总分 1–10、建议（接收 / 小修 / 大修 / 拒绝）、分项（原创性、质量、清晰度、重要性，各 1–4）、优点、缺点、给作者的问题、修改建议、置信度。可选每人 0–3 轮“自我反思修正”。
- 每次模型调用是调度核心的 `model` 任务，整次审稿一棵任务树，可取消，进度推送。
- 汇总（纯函数，可测）：平均分、分歧（最高最低差）、建议分布、缺点合并去重（相似条目归并，标注“N 位审稿人提到”）。
- 打通：每条缺点「送去润色」→ 写作页预填相关段落与修改要求；争议点「送去深度研判」→ 生成一个研究问题 + 由争议点组成的小证据库（按证据库格式保存到 `research/`），跳到深度科研。
- 结果按项目保存，可重新打开。

### 2.2 选题与新颖性检查（arXiv 小助手旁新页签「选题」）
- 输入研究方向（可勾选工坊里的论文作背景）→ 生成 N 个点子：一句话、动机、实验方案草案；打分（有趣度、可行性、新颖性，各 1–10）与理由。
- 新颖性检查：**OpenAlex**（免 Key，`https://api.openalex.org/works?search=…`，带 `mailto` 参数请填写为空或由用户在设置里选填）检索相近工作；可选 Semantic Scholar（用户自填 Key 时）。列出最接近的 3–5 篇（标题、年份、链接），判断“已有人做过 / 部分重叠 / 未见”及理由。
- 联网：沿用第一批 arXiv 的“首次使用说明一次”机制（可共用同意状态或另设一项，说明会访问的地址）；遵守 OpenAlex 的礼貌速率。
- 点子可：加入证据库草稿、开始深度研判、导出 Markdown（走现有导出 / 审批路径）。

### 2.3 AI 使用声明（写作页小工具）
- 统计本项目在论文工坊 / 深度科研里实际用过的功能（翻译、润色、纠错、模拟审稿、选题、深度研判，按记录推断），生成一段中 / 英 AI 使用说明草稿，用户可编辑、复制。纯本地拼装即可，必要时可选调用模型润色。
