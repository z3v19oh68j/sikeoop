## 后端（Codex）
- 新建 `src/main/browser/cdp/**`：基于 `webContents.debugger` 的会话管理（attach/detach、崩溃/导航后重连、命令超时、事件分发），不引入 Playwright/Puppeteer 等依赖，不开远程调试端口。
- 快照：`Accessibility.getFullAXTree` + `DOM` 生成精简树，元素编号用 `backendNodeId`（对外映射成短编号，页面重绘后仍有效，节点消失时报“元素已不在”）。
- 可操作性检查：存在 → 可见（必要时 scrollIntoViewIfNeeded）→ 两帧稳定 → 可用 → 命中检测未遮挡；不满足短轮询重试（默认 3s），失败返回原因（如“被 X 挡住”）。
- 点击 / 输入 / 按键改走 `Input.dispatchMouseEvent`、`Input.insertText`、`Input.dispatchKeyEvent`；事件驱动等待（lifecycle networkIdle、在途请求计数、DOM 静默）替换 `settle()` 的固定睡眠。
- 保持 `browser-tools.ts` 现有 6 个工具名和参数兼容；提交表单类点击的审批逻辑不变；密码填充预加载脚本不动。
- 单测 `test/browser/**`：用假 debugger（注入 sendCommand/事件）测精简树生成、编号映射与失效、可操作性检查各分支、等待逻辑超时、重连。
- 汇报 `docs/自动化浏览器-第一批后端汇报.md`（仓库内）。
