## 接口与行为

### 后台稳定检查

检测目标 document.visibilityState；hidden 时用 DOM.getContentQuads 两次采样，间隔 50ms，位置容差 0.5px；可见页面保留两帧采样。之后仍检查存在、可见、disabled、视口、命中目标/后代及 iframe 父层遮挡，不以后台为由跳过检查。补后台静止、移动、遮挡、disabled 测试。

### 批量动作

`browser_act` 支持 `actions` 数组（最多 100 步），或原单动作字段；两者不能同时提供。动作包括 click / fill / press / select / check / hover / scroll / upload / wait_for，旧 type 保留为 fill 兼容别名。

返回 JSON：`{completed, failedStep, reason, total, url, title}`。`completed` 为成功完成步数；failedStep 为 1-based 失败步骤，成功时 null；失败步骤以及后续步骤不算完成。没有回滚已完成步骤。空字符串 fill 可用于清空。批内审批拒绝或取消立即停止。

```json
{"actions":[{"action":"fill","ref":1,"text":"中文"},{"action":"check","ref":2,"checked":true},{"action":"click","ref":3},{"action":"wait_for","wait":{"kind":"text","text":"提交成功","timeout":5000}}]}
```

click 仍先获取 submits/label，沿用原提交表单类审批链；现在审批依据 ref 所属 frame origin，而不是只看顶层 origin。无 ref 按键保守检查全部 frame 的外部 origin。审批通过后复核 origin，变更即失败。

### 快照

`browser_snapshot({diff?: boolean, scope?: number})`，scope 为快照编号；包含该 DOM 子树、shadow/contentDocument 与其 OOPIF 后代。引用编号按 CDP session 隔离且不复用。主文档更换失效全部引用，子文档更换仅失效相应 session 引用。

diff 基线按 scope 保存；返回新增、消失、文字/呈现变化及“其余不变”。第一次 diff 无基线时全部视为新增；主文档更换重新建立基线。每个 target 仍有原精简树 160 条上限，因此截断边界改变也可能呈现新增/消失，并非完整 DOM 审计日志。

### 等待与抽取

- `browser_wait`：kind 为 text / element / url / network_idle；text 非空且检查可见文字；element 使用 ref 或 CSS selector，state 为 visible/hidden；url 指定值时等匹配，不指定值时等相对开始时的网址变化；timeout 默认 5000ms、最大 60000ms。network_idle 使用在途请求与 500ms 静默窗口，持续请求超时不伪成功。
- `wait_for` 动作的 wait 字段使用相同结构。
- `browser_extract`：`{kind:"table"|"list", ref?, selector?}`，纯 DOM 返回 `{kind:"table",rows:[...]}` 或 `{kind:"list",items:[...]}`；去除 input/textarea/script/style，最多 500 行/项、文本 2000 字符。不读取密码值、不调模型。selector 默认在主文档查询，进入 iframe 可使用该 frame 中的 ref；不支持自然语言猜测目标。

### iframe

Target.setAutoAttach(autoAttach, flatten) 接入 OOPIF，初始化子域后才公开子会话，Page.getFrameTree 确认 frameId，命令使用 Electron debugger 第三参数 sessionId。快照合并各 target 及同源 frame AX 树。鼠标使用 iframe content quad 向父级递归换算到主坐标，并验证父级命中；文本/键盘进入目标子 session。iframe 或祖先 3D/perspective 变换保守拒绝；按键唯一焦点无法确定或多个候选时拒绝，不猜测输入目的地。所有 target 密码焦点保护保留。

### 上传、下载、网络

- upload 使用 DOM.setFileInputFiles；1–20 个现存普通文件，仅当前项目内，lexical 和 realpath 双校验。每一次 humanOnly 审批展示真实文件路径与目的地 origin，审批后复核 origin，并再次校验已批准真实路径。允许隐藏 file input（文件选择控件常被隐藏），但必须存在、是 file input、非 disabled，多个文件还须 multiple。
- 下载默认 deny；项目存在时 Browser.setDownloadBehavior 配置到 realpath 校验过的 `.sikeoop/downloads/`。项目切换前 deny；重配置失败仍 deny；重连恢复配置。记录真实 Browser.downloadWillBegin / downloadProgress 事件清单，未知 GUID progress 不采纳；清洗建议文件名，不采用未校验事件 filePath。清单为会话内存，不持久化；expectedPath 是预计落盘路径，不表示已查证磁盘文件名或内容，Chromium 重名处理可能改变实际文件名。
- `browser_network({limit?,downloads?:boolean})` 返回最近请求摘要，最多 200 条；downloads=true 附下载清单。仅白名单常规头，Cookie / Authorization / Set-Cookie / 自定义 token 头均不输出，不含请求体；HTTP(S) URL 删 credentials、全部 query 和 fragment，data/blob 等非 HTTP(S) 地址脱敏，避免内嵌正文泄漏。
- 没有新增 SweetApi 方法；dev-mock 无新增必选缺项。

## 遗留问题 / 未验证边界

- 未启动 Electron、未以真实 webview 跑 fixture 页面；单测为注入的假 debugger 与本地临时文件测试，不等同真实 DOM、CDP 版本、输入法、嵌套 OOPIF/transform/焦点或下载落盘的集成证据。fixture 未改动，也没有起它的 server。
- 文件 realpath 校验和 Chromium 实际读取之间存在不可原子化的文件系统竞争窗口；审批只绑定文件路径和 frame origin，不对页面脚本改变 form.action 作通用冻结。
- CDP 单命令仍有 5 秒超时，等待与可操作性总耗时可能因协议命令卡住超过表面轮询 timeout。
- 保留原外站/提交审批策略：本地页面不额外强制表单审批，上传不论本地/外站均每次本人审批。
