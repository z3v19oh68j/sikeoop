## 1. 免费模型分区
做的时候后端已经落地了这块接口，所以直接用了 `@shared/types`，没有用临时类型：
- 用 `ProviderView.builtinFree` 识别免费供应商，`enabled` 表示开关。
- 单个开关用 `setBuiltinFreeProviderEnabled`。
- 自动发现到的模型数用 `providerDiscoverModels`。
- 先后顺序存在 `routing.builtinFreeOrder` 里。

页面（`settings/FreeModels.tsx`，放在「模型服务商」页、服务商列表上方）：
- **标题**「免费模型」，下面一句说明：「这些模型由 sikeoop 免费提供，auto 会在它们之间自动挑选和切换。拖动卡片调整先后，排前面的先用。」
- **每张卡片**显示：
  - 序号和拖动把手；
  - 名称 + 状态（可用 / 出错 / 已关闭）；当前在用的标「使用中」；
  - 「内置 · 免费 ·」后面跟模型：auto 显示「自动选模型（发现 N 个）」，固定模型显示模型名。**不显示 Key 和网址**。
  - 往前 / 往后按钮，以及单独的开关。
- **排序**：拖动或按钮调整后，同一份顺序写进 `builtinFreeOrder` 的全部五个用途（chat / coding / hard / subtask / compress），再调用 `setRouting` 保存。
- **列表去重**：免费供应商从下方的普通服务商列表里移除，避免出现两次。

## 2. 脚本录完再起名
- 开始录制不再要名字：调用 `browserFlowStartRecording(undefined, {values})`，面板里提示「录完再起名字」。
- 录制条点「停止」后，在条内弹出命名框（名字输入框 +「保存」+「继续录」）。保存调用 `browserFlowStopRecording(name)`。后端报的重名、非法名错误原样显示在框下面，录制不中断，改完名字再保存就行。
- 脚本列表每项加了「改名」：在原位置变成输入框，调用 `browserFlowRename(旧名, 新名)`，报错显示在面板底部。

## 需要指挥官决定的事
1. **状态只有三种**：你要的是「可用 / 限流 / 额度用尽 / 出错」，但后端现在没有提供每家的运行状态字段。界面只能根据开关和配置是否完整显示「可用 / 出错 / 已关闭」。要显示限流和额度用尽，需要后端在 `ProviderView` 里给一个状态字段。
2. **排序是所有用途共用一份**：后端支持按用途分别排序，界面上只有一个列表，会把同一份顺序写进全部五个用途。要按用途分别排，需要另做界面。
3. **免费供应商不能点开看详情**：它们从普通服务商列表里移除了，免费区的卡片没有「设为当前使用」或展开详情。现在只能靠 auto 路由用上它们。

### 状态按 `ProviderView.health` 显示
- 开关关着（`enabled === false`）：显示「已关闭」，优先于 health。
- 没有 health：显示「还没用过」。
- 有 health：显示「可用 / 限流 / 额度用完 / 出错 · x 分钟前」。时间不到 1 分钟显示「刚刚」，超过 1 小时改用「x 小时前」，超过 1 天改用「x 天前」。`message` 作为鼠标悬停说明。
- 这样就去掉了上一节第 1 条「状态只有三种」的限制。

### 手动选用
- 打开着、而且不是当前在用的卡片，显示「设为当前使用」，调用 `setActiveProvider(id)`。成功后按切换服务商处理（`onChange(s, true)`），当前对话会交给它接着做。
- 当前在用的那张标「正在使用」；关闭的卡片不显示这个按钮。
- 后端报错（比如「这个免费模型已关闭，先打开再选用」）显示在分区底部。
- 这样就去掉了上一节第 3 条「免费供应商不能点开看详情」的限制。
