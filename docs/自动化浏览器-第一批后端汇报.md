## 改动文件

- `src/main/browser/cdp/session.ts` — 可注入 debugger transport；并发 attach 初始化合并，命令超时、detach 时拒绝在途命令、事件分发、重连和 dispose；启用 Page/DOM/Accessibility/Runtime/Network 与 lifecycle 事件。新文档重新请求完整 DOM，以恢复 DOM 变更订阅。
- `src/main/browser/cdp/page.ts` — AX + pierced DOM 精简树；backendNodeId 与不复用的短编号映射；导航/文档更换/崩溃/断开后失效。仅列交互节点、标题和有名称的地标，不返回输入框 value。实现存在、可见、滚动、两帧稳定、disabled、命中本身或后代检查；短轮询失败给出原因。点击、输入、按键使用 CDP Input；select/scroll 也脱离旧 preload 编号。
- `src/main/browser/service.ts` — webview 生命周期接入 CDP；快照和动作委托新底层；删除旧 agent RPC 和固定 settle 睡眠，替换为事件驱动空闲等待。保存密码、历史、截图和控制台逻辑保留。
- `src/main/tools/browser-tools.ts` — 仅更新编号有效期说明；现有 6 个工具名、schema 参数、外站/提交表单审批代码不变。
- `test/browser/cdp.test.ts` — 13 个零依赖假 debugger 测试，覆盖精简树、密码标识、编号与失效、attach/事件/重连/清理、命令超时/断开拒绝、网络/DOM 空闲与超时、可操作性失败分支、后代命中、CDP 点击/中文输入/按键及密码操作拒绝。
- `docs/自动化浏览器-第一批后端汇报.md` — 本汇报。

## 安全边界 / 保守处理 / 遗留问题

- 未修改 `src/renderer`（含 dev-mock）、`src/preload/browser.ts`、shared 类型、依赖或 `test/fixtures/browser-pages/`；未安装、联网、启动应用或 git 提交。保留工作区既有改动。
- 没有新增 SweetApi 方法；dev-mock 无新增缺项，node/web 两端 typecheck 均为 0。
- 不开远程调试端口，只操作 BrowserService 所绑定 webview 的 debugger；detach/crash 后在下一次命令或 did-finish-load 重连，不自动 reload 用户页面。
- 密码字段快照不输出 value；阻止目标密码字段的输入和点击；按键检查当前 DOM/AX 焦点，禁止向密码字段发送键。密码填充仍完全走原预加载路径。
- 第一批不做 OOPIF Target auto-attach，跨源 iframe 完整穿透和会话坐标转换留第二批；不新增批量动作、工具、上传下载、增量快照或体验层。
- 操作检查默认重试窗口 3 秒、间隔最多 50ms；单个 CDP 命令另有 5 秒超时，因此协议卡住时，总返回耗时可能超过重试窗口。两帧采样有 120ms 保护，后台页面无法产生帧时返回「元素仍在移动」，不跳过稳定性检查强行操作。
- 空闲判定使用生命周期/DOM/网络事件和在途请求计数，默认静默窗口 80ms、最长等待 3 秒；持续请求页面明确报超时，而不是悄悄成功。静默窗口用于去抖，不是每步固定睡眠；空闲并不保证未来不会出现延迟任务。
- select 保持原兼容语义（设置选项并派发 input/change），scroll 使用 DOM/Runtime；截图和控制台本批保持原实现。
- 未进行真实 Electron/CDP 版本、DevTools 争用、closed shadow DOM 焦点、页面脚本篡改原生 API、中文富文本编辑器的运行验证；假 debugger 测试不能替代这些验收。
