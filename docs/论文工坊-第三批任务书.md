- **Quarto**：检测（PATH / 常见安装位置，显示版本）与安装指引；一键渲染 `.qmd` / `.md` → PDF（默认 Typst）/ Word / HTML，作为调度核心任务、可取消、失败给要点；论文模板（标题、作者、摘要、`references.bib`、CSL：中文 GB/T 7714、英文 APA）——**CSL 文件来源与许可要核对**（官方样式库为 CC BY-SA 3.0，随附须保留署名；若不随附，则首次使用时下载并说明）；实时预览（保存后重新渲染，输出在项目内，可在 sikeoop 里打开）。
