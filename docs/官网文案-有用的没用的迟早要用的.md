## 第一幕：有用的

**幕标题**：有用的
**一句话**：今天打开就用得上。用不上算本鲸输。

### 1. 改什么，先给你看
改动先变成一张卡片：改了哪几行、改成什么，红绿标出来，再用一句大白话说为什么改。你点「同意」它才写进去。

### 2. 跑什么，先说清楚
装依赖、跑测试之前，先告诉你这条命令是干嘛的。会删文件、会推到网上的，额外标红提醒。

### 3. 改坏了？一键撤回
每一轮改了哪些文件都记着，不满意整轮撤回。不会 Git 也能回到刚才。

### 4. 想盯着，还是全交给它
三种模式随时切：
- **每一步都问你**——刚开始学，就这个。
- **交代完去忙别的**——审批小助手替你看一眼再放行。
- **连确认都懒得点**——危险的那几类命令它碰不了，推送和发布照样等你点头。

### 5. 动手之前，先问你
开新项目、加大功能前，它先看你项目里已经用了什么，去 npm / PyPI 查真实的版本和下载量，再问你最多 4 个问题——推荐的放第一个，拿不准就点「都按推荐来」。

### 6. 换模型，不用从头来
DeepSeek、通义千问、Kimi、智谱、豆包、MiniMax、小米 MiMo、Claude……用哪家填哪家的 Key。中途换模型，之前读过的文件、做到哪一步，都原样交给新模型，**不用再读一遍**。

### 7. 模型掉链子，自己顶上
当前模型限流、欠费、断网了，排好的备用模型自动接手，同一步接着做。简单的问题还能自动交给便宜模型，省钱。

### 8. 额度用完？它定个闹钟
Claude Code、Codex 的额度用完了，sikeoop 读出几点重置（读不出就等 5 小时），到点自动跟它说一句「继续」。你中途自己接手了，它就不多嘴。

> 鲸鱼娘：「你睡你的，本鲸盯着。」

### 9. 记得你，也记得上次做到哪
你的习惯、项目约定、上次没做完的事，都记着。密钥和手机号写进记忆前就抹掉；所有记忆只在你自己电脑上，记错了随手删。

### 10. 先把门关好，再给它钥匙
装技能前先审核；网页和插件里叫 AI 干活的话，它只当资料、不照做；读写文件只在你打开的项目里；对话和代码都留在本机。

## 第二幕：没用的

**幕标题**：没用的
**一句话**：对写代码毫无帮助。但我们做得很认真，你就看看嘛。

> 鲸鱼娘：「这一节可以跳过……才怪，给本鲸好好看完。」

### 1. 一条嘴毒的鲸鱼娘
问简单问题会被笑两句，答案一个字不少。懒人模式下嘴更毒。
*用处：零。陪伴感：满。*

### 2. EVA × 初音未来 皮肤
整套重画的图标、壁纸，连更新提示都有专属的大卡片——就为了你点「重启并更新」的那一秒。
*用处：零。帅：是真的帅。*

### 3. 灵动岛
屏幕最上面一颗小胶囊：AI 在想、在改、在等你，一眼就知道。你本来也可以切过去看的。
*用处：约等于零。偷懒：省了一次切窗口。*

### 4. 会叠起来的书签侧栏
二十多个按钮收成几叠书签，鼠标一放就像扇子一样展开，当前页面的书签还会自己“抽出来”。
*用处：其实有一点点。但主要是好看。*

### 5. 点一下海面
首页的海，点一下会起涟漪。
*用处：没有。我们就是想做。*

### 6. 提示音
AI 干完活「叮」一声，等你批准「咚」一声。可以关。
*用处：你戴耳机的时候有用。*

## 第三幕：迟早要用的

**幕标题**：迟早要用的
**一句话**：现在用不上没关系。写着写着，你会回来找它们的。

> 鲸鱼娘：「先放着。等你哪天觉得一个 AI 不够用了，再来求本鲸。」

### 1. 一个 AI 不够，就叫一群
同时开 Claude Code、Codex，让它们互相派活。忙的排队，不打架；谁改了哪些文件、有没有越界，做完自动列出来。所有任务都在「调度台」里，一眼看全，一键取消。

### 2. 别的编程 CLI 也能接
opencode 这类命令行 AI，写一个 JSON 就能接进终端，和 Claude Code、Codex 一起排队干活。

### 3. 让它定时自己干
画一张小流程图：每天几点跑测试、出问题就让 AI 修、修完再测。睡醒看结果。

### 4. 群聊：让几个模型吵一架
把 DeepSeek、通义、Claude 拉进一个群一起讨论方案。不同的群可以同时吵。

### 5. 用手机遥控电脑
人在外面，用手机派活、看进度、点批准。全程端到端加密，中继只转它看不懂的密文。（安卓 App 内测中）

### 6. 还在做的（标「还在做」）
- **深度科研**：几家模型互相攻击对方的推理链，最后告诉你哪些结论站得住、哪些吵不出结果。
- **论文工坊**：读论文、全文对照翻译、把论文变成证据库、润色纠错、模拟审稿、接 Zotero 引用、用 Quarto 一键出 PDF。
- **一键发布**：做好的网页，点一下拿到能分享的链接。

*做好了会在更新公告里告诉你。不会突然塞给你。*

1. 现在下载区写的 Windows 版本是 **4.1.56**，但服务器上的自动更新还是 4.1.3，4.1.56 / 4.1.57 都没发过。4.1.58 上传后，下载区要改成 4.1.58 的文件名和大小，并更新 SHA256。
