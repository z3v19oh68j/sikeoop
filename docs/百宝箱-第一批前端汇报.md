## 页面
- **提问区**：顶部是问题输入框和「发给 N 家」按钮。
  - 「发给」显示已选站点的小标签，点一下就去掉。默认选 3 家：先选收藏的，再选能直接带问题打开的站点，已隐藏的不选。最多 4 家。
  - 选了两家以上时可以「存成组合」（起个名字）。已存的组合显示成小标签，点一下套用，旁边的 × 删除组合。
- **打开方式**：点「发给」后，对每家调用 `toolboxOpenUrl(id, q)`，在页面里 1–4 栏并排打开 `<webview partition="persist:sikeoop-browser">`，和内置浏览器是同一个会话，登录状态共用。每栏标题栏有站点名、favicon、关闭按钮。
- **复制粘贴提示**：没有网址模板的站点，后端会把问题写进剪贴板，并返回 `copied: true`。这时页面弹出「问题已复制，在『X』里粘贴即可」，对应那一栏标「粘贴问题」。
- **卡片墙**：按「收藏 / 国内 AI 搜索 / 国内 AI 助手 / 海外 / 学术 / 编程 / 我加的」分区。
  - 每张卡显示 favicon（运行时从站点取 `/favicon.ico`，取不到就不显示，不打包别家图标）、名字、一句特点，以及标签：复制粘贴、要登录、登录更好用、国内直连。
  - 点卡片单独打开（带上当前问题）。卡片右侧有勾选框（发给它）、收藏、「⋯」菜单（隐藏 / 不再隐藏；自己加的站点可以删除，需要二次确认）。
  - 卡片可以拖动排序，结果存进 `order`。已隐藏的可以点「显示已隐藏的 N 个」找回来。
- **自定义站点**（「我加的」→「添加站点」）：名字、首页、带问题的网址（可以不填）。
  - 前端先校验：首页必须是 http(s)；网址模板必须是 http(s) 并包含 `{q}`。
  - 新站点 id 用 `custom-时间戳`，分类为 custom，登录标为「可选」，存进 `prefs.custom` 后重新读取 `toolboxSites`。
- **保存**：收藏、排序、隐藏、组合、自定义站点都通过 `toolboxSavePrefs` 保存。
- 页面不代登录、不读取或抓取别家网页内容，页面上也写明了这一点。
