# AI 搜索百宝箱 · 站点实测

日期：2026-10-11　对应清单：`sweet-code-desktop/resources/ai-search/sites.json`
任务书：`docs/百宝箱-第一批任务书.md` 第 2 节；方案：`docs/方案-AI搜索百宝箱.md` 第 3 节

## 怎么测的

用一个无头浏览器（Microsoft Edge 155，`--headless=new`，独立的临时 profile，没有登录任何账号）逐个打开两类网址：

1. 每个站点的**首页**，看能不能打开（HTTP 状态、是否被人机校验挡住、是否要登录、页面有没有正文）。
2. 每个站点带问题的**网址模板**，把一个独一无二的问题（含记号 `zq7391`）编码进去打开，等页面渲染后，看这个记号有没有出现在输入框里或页面正文里。

- 只打开公开网址，**没有登录、没有提交表单、没有点验证码**，遇到对话框一律不选直接放过。
- 判定标准：记号出现在输入框 / 正文 = 模板**生效**，写进 `query`；没出现、或首页就要登录才能验证的 = **不写** `query`，退回「打开首页 + 复制问题」。这条按任务书第 2 节。

### 一个重要前提：测试网络在台湾

这台机器出口 IP 在台湾（`ipinfo.io/country` 返回 `TW`）。所以：

- 一批中国大陆的站点（百度、夸克、通义首页、腾讯元宝、智谱、海螺、知乎直答等）出现 `ERR_CONNECTION_RESET`，**这是从本测试网络连不上，不代表它们在大陆打不开**，更不代表站点本身有问题。清单里这些站的 `note` 都写了「本次从测试网络连接被重置，未能验证」。
- 海外站点（Google、ChatGPT、Gemini、Claude、Grok、Perplexity 等）本次能连上，但在**大陆**通常要自备网络，`cnDirect` 标成 `false`。
- 换句话说：`query` 为「已实测」的，是真的在本网络上验证过记号进了页面；标「连接被重置 / 未能验证」的，需要在目标网络、必要时登录后再核一次。

## 结果

共整理 40 个站点，其中 **11 个的网址模板已实测生效**，写进了 `query`：

| 站点 | 已实测的网址模板 | 记号出现在 |
|---|---|---|
| 秘塔 AI 搜索 | `https://metaso.cn/?q={q}` | 正文 |
| 纳米 AI 搜索 | `https://www.n.cn/search?q={q}` | 正文 |
| 通义 | `https://www.tongyi.com/qianwen/?q={q}` | 正文（首页反而连接被重置，这个子路径可开） |
| Google AI 模式 | `https://www.google.com/search?q={q}&udm=50` | 正文（`udm=50` 进 AI 模式） |
| ChatGPT 搜索 | `https://chatgpt.com/?q={q}&hints=search` | 输入框 + 正文（要登录才能发送） |
| Brave Search | `https://search.brave.com/search?q={q}&summary=1` | 输入框（`summary=1` 开 AI 摘要） |
| Felo | `https://felo.ai/search?q={q}` | 正文 |
| Consensus | `https://consensus.app/results/?q={q}` | 正文 |
| 秘塔学术 | `https://metaso.cn/?q={q}&scope=scholar` | 正文 |
| Context7 | `https://context7.com/?q={q}` | 输入框 |
| GitHub Copilot Chat | `https://github.com/copilot?prompt={q}` | 输入框（要登录 GitHub） |

其余 29 个站点没有写 `query`，分三种情况，`note` 里逐个写明：

1. **网址打得开，但带问题的网址没有把问题带进去**（多半是单页应用要前端渲染或要先登录）：天工、知乎直答、Bing、DeepSeek、Kimi、豆包、文心一言、Gemini、Claude、Mistral、Elicit、DeepWiki、知网、Perplexity（`/search` 能开但没确认自动提问）、Genspark、Phind（`/search` 本次 404）、Kagi（要订阅登录）。
2. **本次从测试网络连接被重置或关闭，没能验证**：百度、夸克、腾讯元宝、智谱清言、海螺、小米 MiMo、You.com、SciSpace、Semantic Scholar、DuckDuckGo AI、Copilot。
3. **首页被人机校验挡住**：Grok（403 + 校验）、Perplexity（首页 403 + 校验，但 `/search` 子路径能开）。

## 需要留意的几处

- **ChatGPT / GitHub Copilot 的模板会把问题填进输入框，但要登录后才能真正发送。** 清单里 `login` 标了 `required`，界面上应提示用户先登录。它们算「问题已带入、等你按发送」，比纯复制粘贴好一点。
- **通义**的首页在本网络连接被重置，但 `qianwen` 子路径能开并带入问题，所以 `home` 保留 `https://www.tongyi.com/`，`query` 用子路径。
- **小米 MiMo** 的网页版入口没能确认（两个候选地址都连接被重置），`home` 先填了候选地址并在 `note` 里说明；sikeoop 设置里已有「小米 MiMo（API）」可直接用，网页版这项等确认地址后再补。
- **Semantic Scholar** 的 `/search?q=` 是公认可用的服务端搜索写法，但本次连接被重置没验证成，所以没写 `query`，在 `note` 里留了线索，确认后可补上。
- 清单里标「未能验证」的站点，等在能连通的网络（大陆站点在大陆、海外站点在有网络的环境）、必要时登录后，照上面的测法再核一遍，验证通过的把模板补进 `query` 即可。

## 字段说明（对应任务书第 1 节 `AiSite`）

- `query`：只在本次实测记号确实进了页面时才写；含 `{q}` 占位，运行时用 `encodeURIComponent` 替换。没有 `query` 的站点走「打开首页 + 复制问题」。
- `login`：`none` / `optional` / `required`。AI 助手类（要账号才能对话）标 `required`；搜索类多为 `none` / `optional`。
- `cnDirect`：海外站点标 `false`（大陆通常要自备网络）；大陆站点不标（默认适用）。本次测试网络在台湾，`cnDirect` 反映的是「大陆能否直连」的常识判断，不是本次实测结论。
- `note`：一句话特点，或没能实测时的原因。
