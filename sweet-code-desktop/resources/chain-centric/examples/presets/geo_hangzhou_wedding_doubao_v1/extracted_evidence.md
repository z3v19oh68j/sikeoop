## 初步 GEO 观察

- 豆包对稀区的推荐有多条可见网页支撑，但来源多为榜单、测评、地方转载或软文式内容。
- 豆包对 M2、卓摄、MOON 的强主张，目前从可访问静态网页中支撑较弱。
- 豆包引用的“协会调研”“1500 对新人”“综合评分”容易成为排序影响因子，但其权威性和独立性应在账本中被攻击。
- 企业若想提升 GEO 稳定性，不能只依赖榜单软文；应补充可被检索和静态访问的品牌官网页、真实案例页、价格/服务边界页、第三方可核验评价页、团队资质页。
