# geo_hangzhou_wedding_doubao_v1

这是一次 GEO 读法固定输入包。

## 用法

- `question.txt`：让 Chain-Centric V5.1 审计豆包“杭州明星质感婚庆拍摄 TOP4”回答。
- `repository.json`：预存证据池，混合豆包感知材料和可打开网页证据。
- `extracted_evidence.md`：人工可读的网页提取记录。

## 解释边界

GEO 读法下，证据池不是事实真值池，而是“豆包感知证据 + 本次网页可见证据”的账本输入。

错误、错配、动态页、反爬壳、无法验证来源都应保留，因为这些反映目标 AI 平台的信息环境和证据可见性。
