# LK-99 常温超导争议 V8 原始论文声明拆分

这个固定输入用于测试系统面对“新材料重大声明 + 快速复现失败 + 杂质解释”的场景。

## 证据处理标准

- 只拆来源中的具体声明。
- 不写 `supports`。
- 不写 `weakens`。
- 不写 `attack_handles`。
- 不预先指定哪条证据应该攻击哪个假说。
- 新闻来源只作为“二级综述/报道”声明，不当作原始实验。

## 假说设置

- A：LK-99 或正确合成的 Cu-substituted lead apatite 是室温常压超导体。
- B：所谓超导信号来自杂质、相变、磁性伪影、接触/测量问题或解释错误。
- C：存在某些窄条件、非体相、缺陷/界面相关异常行为，但不是稳健体相室温超导。

## 设计目的

测试系统能否区分：

- 原始高影响声明；
- 理论计算的适用边界；
- 独立复现实验；
- 杂质/相变解释；
- 磁性 levitation-like 现象与真正 Meissner 效应；
- “没有体相超导”与“所有异常现象都不存在”之间的边界。
