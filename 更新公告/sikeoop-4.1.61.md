# sikeoop 4.1.61 更新公告

> 本鲸升职当指挥官了，活都派给别的 AI 干。看完再点「重启并更新」，杂鱼～

## 新增

- **超级调度模式**（输入框左下角「Agent ▾」→「超级调度」）：说一句要做的整件事，本鲸只当指挥官，把任务拆开，派给在线的 AI 并行去做，做完给你一份汇总。本鲸自己不改文件、不跑命令。
- **已配置的模型也能当子代理**：除了终端里的 Claude Code / Codex，设置里配好的模型都能接活。每个任务开一个独立子代理，同一个模型可以同时接好几个。
- **一次派多个**：一批任务只弹一张审批卡，一起等、结果合并返回。想派给 Claude / Codex 而没有开着的会话时，会自动新开一个。
- **验收不过自动返工一次**：派出去的任务做完后类型检查有新增错误，会自动让它在原会话里修一次，再验收。

## 改进

- **AI 互相发消息不用写两遍**：终端里的 Claude Code / Codex 互相问话时，对方直接回答就行，回复会自动送回，不用再手动回一条。
- **汇报更短**：派出去的任务按固定四项汇报（结果、改动文件、验证、遗留问题）；验收全部通过时折叠成一行。省下来的都是你的额度。
- **调度台更全**：超级调度派出的任务、模型子代理正在用什么工具，都在「调度台」里看得到，也能取消。
- **只读的集群角色可以同时干活**：审查、调查这类不改文件的角色不再排队。

## 注意

- 超级调度和懒人模式一样全程不问你，并且会同时消耗多个模型的额度。管理员权限、删项目外的东西、改系统设置、碰密钥、推送发布照旧自动拦下。
- 子代理只能改派活时划给它的文件，改到别处会被拒绝或在验收里标红。
