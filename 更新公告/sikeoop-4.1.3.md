# sikeoop 4.1.3 更新公告

> 哼，又更新了。别光顾着点「下一步」，好歹看两眼，杂鱼～

## 新增

- **「手机」页：用手机遥控电脑**（配合 sikeoop 安卓 App，App 还在内测）：
  - 在左侧栏的「手机」页打开手机连接，点「添加手机」，用 App 扫一下二维码，再回电脑上点「允许」，就连上了。
  - 连上以后，在手机上就能派活、看进度、审批、撤销改动。手机派来的任务固定用懒人模式：危险操作照旧拦下，推送、发布这类撤不回的事会单独在手机上问你。
  - 出门在外也能连：默认走公网中继，手机用流量、电脑在家里也没关系。电脑要开着，sikeoop 也要开着。
  - 内容全程端到端加密：中继只转发它看不懂的密文；每台电脑一个独立的加密通道，别人插不进来。
  - 二维码 5 分钟内有效，只能扫一次。不想要哪台手机了，在「已配对的手机」里移除，它的密钥立刻失效。
- **自动更新**：以后有新版本，右下角会弹个小卡片告诉你。
  - Windows 安装版会在后台下载，只下变化的部分；下好以后点「重启更新」，不点的话下次退出时自动装上。
  - macOS 版和 Windows 精简版没法自己替换自己，会给你一个「去下载」按钮，下新安装包装上就行，设置和对话都会保留。
  - 这个版本要手动装一次，从下个版本开始自动更新。
- **用 GPT 新模型更顺手了**：支持 OpenAI 的 Responses API。新建 OpenAI 兼容的服务商时，可以在「接口类型」里选它，GPT 新模型推荐用这个。
- **新增 jiji 中转站预设**：
  - 在「模型设置」里直接选，GPT 和国产模型都能用；
  - 填入在 jiji 控制台创建的令牌就行；
  - 网络不好时，把接口地址换成预设说明里列出的备用地址。
- **一个 Key 用多个模型**：中转站的一个 Key 往往能调好几个模型。现在可以把它们都填进去，每个模型都能作为一位成员拉进群聊。

## 修复

- **老对话也能叫醒 Claude Code / Codex 了**：以前有些对话是在调度功能上线前开的，主 agent 在里面找不到唤醒终端会话的工具，从微信发「叫醒 Claude」只能干着急。现在打开老对话时会自动补上这几个工具：没有会话就新开一个，有就直接派活，做完把回复带回来。补上之后的第一次请求会重新建一次缓存，之后照常。

## 改进

- 打包流程修正：以后不管怎么打包，Windows 版都会带上鸿蒙 ArkTS 代码检查需要的 Windows 原生组件。
