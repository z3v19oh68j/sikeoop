# sikeoop 4.1.56 更新公告

> 这次改得有点多，本鲸熬了好几个夜。看完再点「重启更新」，杂鱼～

## 新增

- **换模型不用重读文件了**：在设置里换服务商或模型，当前对话会带着之前的工作记录交给新模型接着做，读过的文件不用再读一遍。AI 正在干活时换，会等这一轮做完再交接。打开别的服务商留下的老对话，也能用现在的模型接着聊。
- **模型路由**（设置 →「模型分工」）：
  - **出错自动换模型**：排好几个备用模型，当前模型限流、欠费、服务挂了或断网时，自动换下一个，同一步接着做。
  - **按难度自动选**：简单的提问、翻译用轻量模型，改代码、修 bug 用主力模型，拿不准就不换。默认关着。
  - **按用途分配**：压缩对话摘要、集群和自动化的子任务，可以各用一个便宜模型。
- **调度台**（左侧栏「AI 协作」里的火箭）：派给 Claude Code、Codex、集群和自动化的任务都在这里，能看到谁派给谁、进度、耗时、自动验收结果，也能一键取消。
- **接入更多编程 CLI**：除了 Claude Code 和 Codex，现在 opencode 这类 CLI 写一个 JSON 定义就能接进终端（终端「+」→「添加其他 CLI…」），能和别的 AI 互相发消息、排队接活。自带一个 opencode 的定义当范例。
- **欢迎页「做一个网页」**：点一下就新建项目，三个示例（奶茶店介绍页、个人主页、活动邀请函）点了就开工。

## 改进

- **AI 之间派活更守规矩**：对方正在忙就排队，不再硬塞进它的终端；AI 互相派活有次数上限，用完会停下来等你。
- **派活更稳**：派活前会检查对方能不能写这个目录、依赖装没装；可以指定它只负责哪些文件；做完自动列出改了哪些文件、有没有越界、类型检查有没有新增错误。
- **文件锁覆盖 sikeoop 自己**：sikeoop 改文件时，终端里的 Claude 不能同时改同一个文件，反过来也一样。
- **设置重做**：分成「模型服务商」「模型分工」「编辑器与联网」「界面与输入」四页，按 Esc 能关。
- **插件中心重做**：能搜索、筛选，内置和自己装的分开放；删除收进「⋯」菜单，要再确认一次。
- **左侧栏改成书签**：二十多个图标收成几叠书签，鼠标移上去展开、带名字；当前页面的书签会抽出来。

## 修复

- 主对话叫醒 Claude Code / Codex、给它们派活，现在会先弹审批卡。
- 审批脚本 `claude-approve.sh` 里少了一个空格，等审批的超时时间原来不生效。
- Hooks 帮助里的示例 JSON 引号没转义，复制过去用不了。
- 插件中心「上次的进度」的开关点了没反应：它本来就跟着「长期记忆」开关走，现在写明了。
