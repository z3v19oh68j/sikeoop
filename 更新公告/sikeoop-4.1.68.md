# sikeoop 4.1.68 更新公告

> ChatGPT 订阅也能拿来干活了，本鲸又多了一份口粮。看完再点「重启并更新」，杂鱼～

## 新增

- **用 ChatGPT 账号登录**（设置 → 服务商 → OpenAI →「登录方式」选「ChatGPT 账号登录」）：点「生成登录链接」，在浏览器里登录，把跳转后的地址粘回来就行。之后对话走订阅额度，不用填 API Key。
- **订阅额度条**：ChatGPT 登录后，登录状态下面能看到 5 小时和 7 天两个窗口各用了多少、什么时候重置。
- **订阅模型自动列出**：登录后模型列表直接从你的订阅里拉；拉不到时会给一份常用模型备选，不用手填。
- **Claude 额度重置次数**：用 Anthropic 账号登录时，订阅用量下面多了一栏，能看还剩几次额度重置、每次清空哪些窗口、什么时候到期。目前只能看，不能在这里兑换。

## 改进

- **更新公告好读了**：按「新增 / 改进 / 修复 / 注意」分区排版，每条的重点加粗。右下角的更新卡片先列三条要点，点「查看全部更新说明」再展开全文。
- **手动拷进来的技能默认关闭**：直接放进技能文件夹、没经过安装检查的技能不再自动进对话，要用的话到插件中心手动打开。内置技能和正常安装的技能不受影响。

## 注意

- ChatGPT 账号登录目前只管对话。项目百科、知识图谱、AI 审核、识图这些一次性功能还不能用订阅，选到它时会提示你换一个服务商或改回 API Key。
- 订阅额度条有 3 分钟缓存，刚点过「刷新」又点一次，数字不会变。
- 升级后，以前手动拷进技能文件夹的技能会变成关闭状态，这是上面那条改动的效果，不是丢了。
