# sikeoop 4.1.57 更新公告

> 攒了一大波，本鲸熬了好几个夜。看完再点「重启并更新」，杂鱼～

## 新增

- **换模型不用重读文件**：换服务商或模型时，当前对话带着之前的工作记录交给新模型接着做，读过的文件不用再读。打开别家留下的老对话也能接着聊。
- **模型分工**（设置 →「模型分工」）：备用模型在当前模型限流、欠费、断网时自动顶上；可按难度自动选轻量 / 主力模型（默认关）；压缩摘要、子任务可以各用便宜模型。
- **调度台**（侧栏「AI 协作」）：派给 Claude Code、Codex、集群、自动化的任务都在这里，能看进度、验收结果，能一键取消。
- **接入更多编程 CLI**：opencode 这类 CLI 写个 JSON 就能接进终端（终端「+」→「添加其他 CLI…」）。
- **新服务商「小米 MiMo（API）」**：按量计费的普通 Key 也能用了，和 Token Plan 分开。
- **欢迎页「做一个网页」**：点一下新建项目，三个示例直接开工。

## 改进

- **AI 派活更守规矩**：对方忙就排队；AI 互相派活有次数上限；派活前检查目录和依赖，做完自动列出改了哪些文件、有没有越界。
- **群聊**：不同的群可以同时聊，「停下」只停当前这个群。
- **设置、插件中心重做**：分页清楚了，能搜索、筛选，删除要二次确认。
- **侧栏改成书签**：鼠标移上去展开、带名字。
- **自动更新**：可以关掉「自动下载」，自己决定什么时候下；更新说明能看全文。EVA × MIKU 皮肤有专属的更新卡片。
- **文件锁**：sikeoop 和终端里的 Claude 不会同时改同一个文件。

## 修复

- 主对话叫醒 Claude Code / Codex、给它们派活前，会先弹审批卡。
- 审批脚本 `claude-approve.sh` 的超时不生效。
- Hooks 帮助里的示例 JSON 复制过去用不了。
- 浏览器预览模式（开发用）启动报错。
