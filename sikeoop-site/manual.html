新手手册

从打开项目，到让 AI 替你写完

sikeoop 每个功能是做什么的、在哪里点、可以怎么说。软件里点左下角的「帮助」也能看到同一份手册，还能一键跳到对应的功能。

第一步让 AI 干活让 AI 更懂你项目工具装技能、接工具多位 AI 一起干随手就能用花了多少为华人准备的小巧思

第一步

装好以后，三分钟就能让 AI 帮你写出第一个页面。

打开或新建一个项目

项目就是电脑上的一个文件夹，你的代码都放在里面。已经有代码就「打开项目」；从零开始就「新建项目」，选一个空文件夹。AI 只能读写这个文件夹里的东西。

在哪：首页 → 打开项目 / 新建项目

选一位伙伴

每位伙伴对应一个 AI 模型。国内的 DeepSeek、通义千问、Kimi、智谱、豆包、MiniMax、小米 MiMo 都能直接连上。用哪个服务商，就去那家官网申请一个 Key 填进来。

在哪：标题栏右上角的伙伴头像，或左边栏「全部伙伴」

说出你想做什么

在右边的对话框里用大白话说就行，不用懂术语。说得越具体越好：给谁用、长什么样、要有哪些按钮。

在哪：打开项目后，右边的对话栏

试试这样说帮我做一个记账网页，能记每天花了多少钱，按月份看总数

重看新手教程

第一次打开时的引导可以随时重看：首页一段，项目里一段。

让 AI 干活

AI 会读文件、改代码、跑命令。做每件事之前，都先让你看到。

改动卡片：先看再同意

AI 想改文件时，对话里会出现一张卡片：红色是删掉的，绿色是新加的，改了的那几个字单独高亮，下面一句话说明为什么改。点「同意」才真的写进文件，点「不要」它会换个做法。想看整个文件，点「左右对比」。

在哪：对话里的改动卡片

命令也先问你

装依赖、跑测试之前，它会说清楚这条命令是干嘛的。会删文件、会推送到网上的命令会额外标出提醒。

改坏了，整轮撤销

每一轮对话改了哪些文件都记着。不满意就点那一轮下面的「撤销」，所有文件回到改之前，不用会 Git。

在哪：每轮回答末尾的「改了 N 个文件」

三种工作方式

输入框左下角切换。Agent：每一步都问你，适合刚开始学。长任务：交代完去忙，「审批小助手」代你把关，拿不准的还是叫你。懒人：完全自己做，不再问你，危险命令（sudo、删项目外的文件、改系统设置、推送发布）会被自动拦下。

在哪：输入框左下角「Agent ▾」

做新东西前，它会先问你

新建项目、加大功能之前，它会先查 npm、PyPI 上候选库的最新版本和下载量，再用一张问题卡片问你几个只有你能定的事。推荐的选项放第一个，拿不准就点「都按推荐来」。

看它的计划和进度

要好几步才能做完的事，它会先列一份计划清单，做的时候一项项打勾，你随时知道做到哪了。

截图、文件直接丢进来

报错截图、设计稿、PDF、代码文件，粘贴或拖进输入框就行。图片会先由识图模型看一遍，再交给 AI。

在哪：输入框，或输入框旁边的回形针

试试这样说（拖一张报错截图进来）这是什么意思？怎么修？

内置浏览器：边改边看

做网页时不用切到别的浏览器。点编辑器标签栏右边的地球图标打开，可以和代码左右分屏：左边改，右边马上看到效果。开发服务器一跑起来，它的地址会自动在这里打开。AI 也能用它：看页面、截图、点按钮测交互、读控制台报错。去外部网站点击、填表之前它会先问你；遇到登录它会请你自己登。登录状态、Cookie、访问历史都存在这台电脑上；保存的密码用系统钥匙串加密，只有你点钥匙图标时才会填入，AI 看不到。地址栏直接打字就是用必应搜索，可以在「⋯ → 设置」里换成百度或 Google。

在哪：编辑器标签栏右边的地球图标

试试这样说打开 localhost:5173 看看首页，按钮点了有没有反应，控制台有没有报错

Markdown 文件看排版好的样子

打开 .md 文件（比如 README.md、AI 写的说明文档），文件路径那一行右边可以切换「源码 / 分栏 / 预览」：预览显示排好版的标题、表格、清单和流程图，分栏就左边改右边马上看到。文档里的相对链接点一下就在编辑器里打开那个文件。选过一次以后，别的 .md 文件也按这个方式显示。

在哪：打开 .md 文件后，编辑器顶部路径栏的右边

终端

开发服务器这种一直运行的命令，AI 会写在代码块里，点「在终端运行」就在下面的终端里跑起来。Windows 上命令统一在 Git Bash 里运行。

在哪：编辑器下方的终端面板

让 AI 更懂你

它会记住你的习惯和项目的约定，下次不用再说一遍。

长期记忆

你说「以后注释都用中文」，它会记下来，以后每次新对话都带上。聊完空闲 10 分钟，它会把最近几次对话里值得记的整理进来：只提过一次的先放着，再提到才记；和旧记忆矛盾的，等你选。很久不用的记忆会放进归档，需要时还能找回来。

在哪：左边栏的大脑图标「记忆与代码索引」

试试这样说记住：我喜欢简洁的界面，按钮都用圆角

接着上次做

在同一个项目里开新对话，它会先看上次对话的摘要（7 天内的），知道上次做到哪、还剩什么没做。

试试这样说接着上次没做完的继续

项目规则

项目里放一个 AGENTS.md 或 CLAUDE.md，写上「用 Vue 写」「不要动 config 文件夹」这类规则，AI 每次都会照做。

自动找相关代码

项目大了也不怕：每条消息发出前，它会在代码索引里找出可能相关的几段代码一起给 AI，省得它到处翻文件。

在哪：「记忆与代码索引」→ 代码索引

项目工具

写代码之外，帮你看懂、整理、展示一个项目。

项目百科

AI 读完整个项目，写一份说明书和架构图。接手别人的代码时特别有用。

在哪：左边栏「项目百科」

知识图谱

把项目代码或开发文档拆成节点和关系图，一眼看清谁调用了谁。

在哪：左边栏「知识图谱」

原型工坊

还没想好界面长什么样？先在这里让 AI 画几屏可点击的原型，满意了再写成真代码。

在哪：左边栏「原型工坊」

归档项目

做完的项目打包成一个 zip 存起来，以后解压就能接着做。

在哪：左边栏「归档项目」

Android 模拟器

做手机 App 时，在 sikeoop 里直接打开模拟器看效果。

在哪：左边栏「Android 模拟器」

装技能、接工具

让 AI 学会新本事，比如做 PPT、读 Excel、按某种风格写代码。

资源库：一键安装

挑好的技能和工具，点一下就装上。

在哪：左边栏礼物图标「资源库」

SkillHub 技能商店

国内的技能商店（skillhub.cn），社区上传的技能都能搜到。装之前会先做安全审核：规则扫一遍，再让 AI 读一遍，查有没有藏着恶意指令。高风险的只有你本人能决定装不装。

在哪：资源库 → SkillHub

插件：技能和 MCP

管理已经装的技能，连接 MCP 服务器（让 AI 能操作数据库、浏览器等外部工具）。

在哪：左边栏「插件」

多位 AI 一起干

一个 AI 不够用时。

Agent 群聊

拉几位不同模型的伙伴进一个群，让它们一起讨论一个方案，你看着它们吵完再拍板。

在哪：左边栏「Agent 群聊」

自动化

按时间表自动跑的任务，比如每天早上检查一遍依赖有没有安全更新。

在哪：左边栏时钟图标「自动化」

鸿蒙集群

做鸿蒙应用时，把任务分派给几个专门的子代理（写 ArkTS、写测试、查规范），在控制台里看它们各自的进度。

在哪：左边栏「鸿蒙集群」

让 Claude Code 和 Codex 互相发消息

在 sikeoop 的终端里开着 Claude Code、Codex 时，它们能互相看到、互相留言，分工做一件事。

在哪：终端面板

随手就能用

不在 sikeoop 窗口里时也能用。

灵动岛

屏幕顶部正中的小胶囊，显示 AI 正在做什么、做完没有。切到别的窗口也能看到。

随手截图问 AI

Mac 上在同一个地方快速点四下，Windows 上按鼠标侧键，就能框选屏幕任意一块截图，直接问 AI。

按住说话

Mac 按住右边的 Option，Windows 按住右边的 Ctrl，说完松手，说的话会变成文字打进当前的输入框，任何软件里都行。用小米 MiMo 的语音识别，中文识别得准。

关窗口不停工

关掉窗口只是缩到托盘（Mac 是菜单栏），长任务照样在跑；需要你的时候会弹系统通知。

花了多少

心里有数。

用量统计

每天用了多少 token、花了多少钱，按模型分开看。

在哪：左边栏「用量统计」

缓存命中率

底部状态栏显示这段对话有多少内容命中了缓存。命中的部分价格很低，命中率越高越省钱。缓存不该断却断了时，会变成橙色提醒你。

在哪：底部状态栏

为华人准备的小巧思

这些是 sikeoop 特意为国内用户做的。

全中文，说大白话

界面、提示、AI 的回答都是简体中文。术语非用不可时，顺手用一句话解释。

国产模型直接连

DeepSeek、通义千问、Kimi、智谱 GLM、豆包、MiniMax、小米 MiMo 都内置了接入方式，填 Key 就能用，不用折腾网络。

按人民币算钱，分峰谷

用 DeepSeek 时，费用直接按人民币显示，而且按北京时间区分高峰和闲时价格，闲时写代码更便宜。

国内的技能商店

接入了 SkillHub（skillhub.cn），国内能直接搜、直接装，装之前自动做安全审核。

中文语音输入

按住说话，用小米 MiMo 的语音识别，普通话识别准，说完自动打进输入框。

鸿蒙开发

认识 ArkTS（.ets 文件），配好 DevEco Studio 的 SDK 后有代码提示；还有专门的鸿蒙子代理集群。

微信小程序文件

认识 .wxml、.wxss 文件，在文件树里有对应的图标，一眼分得清。

Windows 上命令不出错

命令统一在 Git Bash 里运行，AI 写的命令在 Windows 和 Mac 上是同一套写法。
