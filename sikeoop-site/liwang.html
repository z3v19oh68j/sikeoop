链心 Chain-Centric V8

面向可审计多模型推理的声明级证据账本

几个大模型一起讨论，留下的对话记录看着透明，其实很难查：哪条主张被攻击过，攻击的是哪一步，之后改没改。链心把这种互动从自由对话换成一本结构化的账本。每个 agent 每轮只能做四种动作，每次攻击都要指到具体的链、版本和步骤；协调层运行时不调用 LLM，也不判断谁对。

V8 新加了声明级证据池：一篇论文可以拆成几条能单独引用、单独攻击的证据声明。它给出的是一张分歧地图，不是答案。

论文自己写明的边界：不主张结果比单个模型更接近真理；一次会话大约要 70 万到 120 万输入 token。

识海—心光持续主体认知架构

MindSea–Heartlight Persistent Agent Architecture（MHPA）

现在的 LLM Agent 大多还是“输入—推理—输出”：人格和情绪是当前上下文里临时生成的。MHPA 走另一条路，让大模型只当语言和推理的组件，在它外面搭一个持续运行的主体状态系统：先验参数（Agent DNA）、动态认知场（识海）、有限的意识访问（心光）、会衰减也会重构的记忆、复合情绪和意图竞争。

人格不一定需要由大模型直接生成；人格可以作为长期认知动力系统运行过程中涌现出的稳定行为模式。

文稿自己写明的边界：讨论的是“意识式的信息流与主体连续性”怎样工程化，不对机器是否真的拥有意识、疼痛或自由意志下结论。
