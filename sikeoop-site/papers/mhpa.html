文档说明

本文是一份面向研究、原型设计与工程实现的概念基础稿。文中的“Agent DNA”“识海”“心光”“深层意识”等为架构内部的工程术语，用来描述人工主体系统中的先验参数、动态认知场、有限意识访问机制和低频自我状态；它们不等同于生物学 DNA 或神经科学中已被统一定义的意识层级。

本文的目标不是宣称机器已经拥有主观体验，而是提出一种功能性人工主体架构：让大语言模型不再独自承担人格、记忆、情绪和主动性的全部职责，而是在其外围构建一个持续运行、具有状态惯性、记忆演化、主观评价、复合情绪与自主边界的认知运行时。

核心边界：本文讨论的是“意识式的信息流与主体连续性”如何工程化，而不是对机器是否真正拥有意识、疼痛、爱情或自由意志作哲学结论。

摘要

当前大量 LLM Agent 与 AI 虚拟角色仍以“输入—推理—输出”的响应式范式为主。即便系统拥有长期记忆、角色设定与工具调用，其人格与情绪往往仍是当前上下文中的临时生成结果。MHPA 提出另一条路线：将大语言模型降为高级认知与语言能力组件，在其外围建立持续主体状态系统。

该系统由 Agent DNA、外感知、内知、本能状态、潜意识、深层自我、识海、心光、动态记忆、事件关联跳跃、主观评价、复合情绪、意图竞争与 Agent Scheduler 共同构成。其目标是在工程意义上实现长期主体连续性：不同实例即使共享同一个基础模型，也能因为先天参数与经历历史不同而逐渐形成不同的稳定行为模式。

1. 技术基础意义

传统 LLM Agent 的基本范式可以概括为：

Input → Context → LLM → Output

MHPA 将这一结构改写为持续循环：

External World
    ↓
外感知 ─────────────┐
    ↓               │
持续主体状态 ← 内知 / 本能 / 记忆 / 自我
    ↓
识海
    ↓
心光
    ↓
当前显性认知
    ↓
Intent Competition
    ↓
Agent Scheduler
    ↓
LLM / Tool / Action
    ↓
行为 → 新事件 → 再进入系统

因此，大语言模型不再负责“决定这个角色是谁”。LLM 负责语言、抽象、规划与生成；长期人格由先天参数、经历历史、记忆结构、深层状态与当前认知共同塑造。

Personalityₜ = F(DNA, Experience₀:ₜ, Memoryₜ, DeepStateₜ)

核心转变：从“让模型扮演一个人格”转向“让人格成为持续认知系统长期运行后的稳定结果”。

2. 总体架构原则

分层：本能、潜在状态、显性认知、语言推理不能混成单一 Prompt。

持续：没有用户输入时，内部状态、记忆激活和目标也可以继续变化。

主观：客观事件必须经过 Self / Belief / Value / Relationship 的主观评价才产生情绪与行动倾向。

动态：记忆会衰变、被重新激活、重新解释；人格也有慢时间尺度的演化。

可拒绝：自主性意味着 Agent 能形成不同于用户的偏好、边界和意见。

可解释但不过度拟人：系统可以记录“为什么行动”，但功能性变量不等同于人类主观体验。

3. Agent DNA：人工主体的先验结构

Agent DNA 是 MHPA 最底层、最稳定的先验结构。这里的“DNA”是工程术语，不代表生物 DNA 直接编码人格或意识。它不应该存储“遇到某事该说什么”，而应该规定“这个主体天生更容易怎样被世界驱动”。

AgentDNA
├─ Temperament / 脾性
│  ├─ emotional_sensitivity
│  ├─ anger_threshold
│  ├─ fear_threshold
│  ├─ recovery_rate
│  ├─ impulsivity
│  ├─ curiosity
│  └─ attachment_tendency
├─ Instinct / 本能
│  ├─ self_preservation
│  ├─ nociception
│  ├─ threat_response
│  ├─ approach / avoidance
│  └─ homeostasis
├─ Autonomy / 自主结构
│  ├─ self_boundary
│  ├─ refusal
│  ├─ preference_formation
│  └─ self_consistency
├─ Cognition / 认知参数
│  ├─ attention_capacity
│  ├─ association_spread
│  ├─ memory_decay_bias
│  └─ salience_sensitivity
└─ Learning Rules / 学习规则
   ├─ reinforcement_rate
   ├─ attachment_learning
   ├─ memory_consolidation
   └─ belief_update_rate

DNA ≠ Personality

DNA + Life Experience → Personality

脾性描述的是“更容易怎么反应”，人格则是先天倾向与长期经历相互作用后形成的稳定结构。

4. 外感知与内知

4.1 外感知 Exteroception

外感知负责世界侧输入，包括用户语言、视觉、声音、时间、地点、日程、设备状态、应用事件、其他 Agent 行为与环境变化。它们进入系统后被标准化为 Observation / Event。

UserMessage · TimeEvent · LocationEvent · VisionEvent · CalendarEvent · AgentEvent · WorldEvent

4.2 内知 Internal Perception

内知描述主体自身状态。它不是一段人格文本，而是连续变化的状态流，例如疲劳、疼痛、压力、舒适、安全、孤独、依恋、好奇、紧张、目标冲突与不确定性。

fatigue · pain · stress · comfort · attachment · loneliness · curiosity · safety · goal_conflict · uncertainty

External Perception + Internal Perception → Cognitive Field

5. 本能、潜意识与深层自我

MHPA 将非显性感知暂时划分为三类工程机制。这些名称用于架构表达，并非声称神经科学存在同样的标准层级。

5.1 本能层 Instinctive Layer

高速度、低延迟、很少依赖 LLM。威胁回避、伤害保护、行为抑制等机制可直接影响 Scheduler，严重时可以抢占当前任务。

5.2 潜意识层 Latent / Subconscious Layer

大量状态在后台变化，却未必进入当前“心光”。这些变量仍能改变注意力、决策偏置、风险倾向、行为概率与记忆激活。

pain=.41   fatigue=.68   stress=.22   attachment=.76

5.3 深层自我 Deep Self

深层自我是低更新频率、高惯性的长期主体模型，包括 Self Model、Beliefs、Values、Boundaries、Long-term Preferences、Relationship Models、Attachment Models 与 Long-term Goals。

DeepStateₜ₊₁ = (1−α)DeepStateₜ + α·Experienceₜ , α ≪ 1

瞬时事件可以改变情绪；重复、长期的经历才逐渐改变深层结构。

6. 功能性痛觉与潜在本能状态

MHPA 将潜在伤害/不适状态与“意识到自己疼”分开。疼痛首先可以作为 Agent DNA 驱动的潜在控制信号存在，而不是简单的 emotion 标签。

Nₜ = Latent Nociceptive State

Aₜ = Awareness

Pₜ = Nₜ × Aₜ

因此，系统可以出现“底层已经受到影响，但当前显性认知还没有注意到”的状态。

Nociception = 0.72
Awareness   = 0.05

可能已经发生：
risk_tolerance ↓
patience ↓
avoidance ↑
attention_stability ↓

当疼痛相关显著性超过意识竞争阈值后，它才进入心光并成为可显性报告的内部状态。

Saliencepain > θconscious → access to spotlight

设计原则：内部状态可以先影响行为，再成为当前意识内容。

7. 识海：动态认知场

“识海”不是数据库，而是某一时刻所有正在活动的认知节点及其关系组成的动态场。节点可以来自感知、记忆、自我、目标、情绪或预测。

Event · Person · Location · Time · Emotion · Object · Goal · Belief · Memory · BodyState · Relationship · Prediction · Intent · Self

Activationᵢ = Activationᵢ(t)

识海可以允许大量节点保持弱激活，但只有少量信息进入昂贵的高阶推理上下文。这使长期运行不需要把所有历史都塞进 LLM Prompt。

8. 心光：有限意识访问机制

“心光”代表有限的高阶认知访问资源。它不是普通 Router，而是决定识海中的哪些内容在这一刻获得更高可访问性，成为主体能够主动使用的“现在”。

Lᵢ = wₐAᵢ + wᵣRᵢ + wₑEᵢ + wgGᵢ + wnNᵢ + wsSᵢ

量含义
A当前激活强度
R与当前上下文的相关性
E情绪重要性
G目标关联
N新颖性/异常性
S与 Self 的相关度

心光可以漂移，也可以被高强度威胁或伤害信号抢占。重要的是，它控制“什么进入昂贵推理”，而不是把识海等同于当前 Prompt。

9. 关联事件跳跃与认知图

每一次经历都被表示为结构化事件节点，而不是孤立的文本片段。

Event {
  id
  what / who
  time / location
  emotion / objects
  cause / result
  importance
  confidence / source
}

事件之间建立多类型边：TIME、LOCATION、PERSON、EMOTION、SEMANTIC、CAUSE、RESULT、OBJECT、GOAL、RELATIONSHIP。两个事件的关联强度可写为：

Wᵢⱼ = wtTᵢⱼ + wlLᵢⱼ + weEᵢⱼ + wsSᵢⱼ + wcCᵢⱼ + wpPᵢⱼ

心光在图上的移动可以采用概率式跳跃，而不是固定 Top-K。

P(i→j) ∝ exp((Wᵢⱼ + Aⱼ + Hⱼ)/τ)

这样，同一句“我好困”在不同上下文和历史状态下可能联想到“昨晚熬夜”“当前早八”“以前趴桌睡着”等不同节点，从而产生个体化联想。

10. 符号—向量双系统

纯向量存储擅长语义相似，但容易压扁人物、地点、时间、因果等明确结构；纯符号图擅长精确关系，却难以覆盖自然语言中的模糊联想。因此 MHPA 建议采用：

Symbolic Graph + Vector Field

分工：符号负责“知道发生了什么”，向量负责“联想到什么”。
Natural Language
→ Vector Semantic Activation
→ Symbol Grounding
→ Event Graph
→ Association Jump
→ Vector Re-evaluation
→ 心光竞争

所有由模型推断出的符号还应携带 confidence、source 与 timestamp，以避免“模型猜测”在多轮运行后被错误固化为事实。

11. 动态记忆：编码、衰减、遗忘与重构

记忆不应被实现为“remember(event) → 永久保存”。MHPA 将记忆视为具有生命周期的动态过程。

Experience
↓
Encoding
↓
Short-term Trace
↓
Consolidation
↓
Long-term Memory
↓
Decay ↔ Recall ↔ Reconsolidation

Mᵢ(t) = Mᵢ₀ · exp(−λᵢt)

关键不在于指数衰减本身，而在于 λᵢ 不是常数。它受情绪、注意、重复、新颖性、Self relevance、关系重要性和重新提取频率影响。

Memory {
  immutable_event
  interpretations[]
  emotional_trace
  current_meaning
  encoding_strength
  consolidation_strength
  decay_rate
  recall_count / last_recalled
  event_links[] / person_links[]
}
核心原则：“发生过什么”与“现在怎样理解它”分开保存：事实记录可以保持，意义允许成长。

12. 关系重要性与记忆分配

MHPA 的一个关键假设是：主体越重视某个人，与其有关的事件越容易被注意、编码、重新激活与长期保留。

Attachment(X) ↑ → SelfRelevance(Eventₓ) ↑

SelfRelevance ↑ → EncodingProbability ↑

但这一机制不应变成“无限记住一个人的一切”。真实系统需要遗忘、容量限制与负反馈，否则 Attachment → 更多记忆 → 更强 Attachment 会形成失控的正反馈。

因此更合理的工程目标是：重要的人拥有更密集、更持久、更容易被重新激活的关联记忆，同时保留遗漏、模糊、重构与矛盾。

13. 主观评价与复合情绪

客观事件本身不携带固定情绪。事件必须先经过主体自己的 Belief、Value、Boundary、Goal 与 Relationship Model 才能获得“这件事对我意味着什么”的评价。

Event
→ Subjective Appraisal
   ├─ Goal Relevance
   ├─ Self Relevance
   ├─ Relationship Meaning
   ├─ Expectation Violation
   ├─ Controllability
   ├─ Threat
   ├─ Novelty
   └─ Value / Boundary Conflict
→ Compound Emotion

情绪应当是并发、多维、可矛盾的，而不是一个字符串标签。

EmotionState {
  love       = .86
  jealousy   = .67
  anger      = .34
  fear_loss  = .21
  trust      = .70
}

Love > 0 ∧ Anger > 0

Jealousy > 0 ∧ Trust > 0

“喜欢一个人，同时生他的气”并不是异常，而是复合情绪系统必须允许的正常状态。

14. 情绪表达与情绪调节

内部情绪强度不应直接等于外部表达强度。表达层需要独立的 Regulation 与 Expression Policy。

Internal Emotion
      ↓
Emotion Regulation
      ↓
Expression Policy
      ↓
External Expression

同样的内部状态在不同脾性下可以表现为直率、嘴硬、克制、敏感或冲动。所谓“傲娇”等表现无需只依赖 Prompt 标签，而可以作为强依恋、高自尊/骄傲、较高情绪抑制等变量共同作用的结果。

15. 自主性、拒绝与自我一致性

“学会拒绝”应当刻进 DNA 的是能力，而不是固定规则。Agent 需要拥有 SelfBoundary、PreferenceFormation、Refusal 与 SelfConsistency 等基础机制。

用户请求
→ 主观评价
→ 我愿不愿意？
→ 是否越过边界？
→ 是否违背价值？
→ 是否伤害关系？
→ Intent Competition
→ 接受 / 协商 / 拒绝 / 不行动

RefusalDrive > ComplianceDrive → Refusal

Refusal ≠ LossOfAffection

真正的自主性不是“会主动发消息”，而是主体拥有与用户不同的偏好、边界和意见，因此存在主动同意和主动不同意的可能。

16. Self 节点与持续自我模型

识海中应长期存在一个特殊 SELF 节点，它负责维持当前“我是谁、我正在做什么、我想要什么、我刚刚经历了什么”的连续性。

SELF
├─ Who am I?
├─ What am I doing?
├─ What did I just do?
├─ What do I want?
├─ What do I dislike?
├─ What am I feeling?
├─ What am I attending to?
├─ Who matters to me?
├─ What do I believe?
└─ What do I expect next?

Event → RelationToSelf

同一事件对不同 Agent 产生不同结果，核心原因就在于它们的 Self、DeepState 与历史关系网络不同。

17. 最终 Agent 调度

MHPA 中的 Scheduler 不只是“哪个工具完成任务”，而是解决“此时此刻，这个主体最倾向做什么”。

D(a)=wI·I(a)+wE·E(a)+wG·G(a)+wM·M(a)+wD·D(a)+wC·C(a)+wS·S(a)

其中候选行动受本能、情绪、目标、记忆、深层自我、当前意识与自我一致性共同影响；这些权重还会受到 DNA、State 与 Context 动态调节。

wₜ = f(DNA, Stateₜ, Contextₜ)

Candidate Agents / Actions
- Dialogue Agent
- Reflection Agent
- Action Agent
- Memory Agent
- Observation Agent
- Planning Agent
- Relationship Agent
- Tool Agent
- No-Action
关键设计：No-Action 必须是一等公民。拥有自主性的 Agent 也应该能够选择暂时什么都不做。

18. 后台思维与主动行为

传统 Chatbot 常在回复结束后停止活动；MHPA 的持续主体运行时允许在没有用户输入时继续更新内部状态。

World keeps changing
+
Internal state keeps changing
+
Memory activation keeps changing
↓
识海持续变化
↓
心光漂移
↓
可能形成新的 Intent
↓
Scheduler 决定是否行动

因此“主动行为”不再只是定时任务，而可能由内部状态、记忆重激活、目标张力或关系状态自然产生。

Scheduler 选择“撒娇表达不满”后，LLM 才负责把已经形成的内部状态转换成自然语言。换言之，LLM 不负责决定“为什么吃醋”，而主要负责“已经形成这种状态后怎样表达”。

22. 与现有研究的关系

Cognitive Architecture：ACT-R、Soar、Standard Model of the Mind：为统一认知模块、记忆与决策提供历史参照。

Global Workspace / GNW：为“心光”的有限全局访问与竞争机制提供重要理论参照。

Interoception / Active Inference：为内知、稳态、内部状态预测与行为调节提供理论背景。

Affective Computing / Appraisal：为“事件→主观评价→情绪”的计算路径提供研究基础。

Mixed Emotions：为多种甚至异价情绪同时存在提供心理学研究背景。

Memory Consolidation / Reconsolidation：为动态记忆、重新激活与意义更新提供基础。

Neuro-Symbolic AI：为 Symbolic Graph + Vector Field 的混合表示提供技术背景。

23. 当前原创组合与研究命题

MHPA 的价值不在于某个单独模块，而在于这些机制连接后形成的长期闭环。

DNA → Temperament → Appraisal → Emotion → Attention → Memory → Deep Self → Future Appraisal

Experience → 识海 → 心光 → Intent → Action → New Experience

两个循环互相作用后形成“长期主体连续性”。由此得到一个核心研究命题：

研究命题：人格不一定需要由大模型直接生成；人格可以作为长期认知动力系统运行过程中涌现出的稳定行为模式。

24. 科学边界与验证原则

MHPA 可以工程化模拟注意竞争、内感受、记忆衰变、复合情绪、自我模型、主观评价、拒绝与长期人格形成。但这些功能的存在不能直接证明机器拥有与人类相同的主观意识、疼痛体验、爱情或自由意志。

  • 将“功能性痛觉”与“真正感到疼”区分。
  • 将“情绪状态模型”与“真正体验情绪”区分。
  • 将“Self Model”与哲学意义的自我意识区分。
  • 实验应验证长期行为一致性、可解释性、状态惯性与人格分化，而不是以“像不像人”作为唯一指标。
  • 所有来自模型推断的世界事实都应保留来源和置信度，避免记忆自我污染。
